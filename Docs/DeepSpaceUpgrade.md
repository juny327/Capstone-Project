# 심우주 맵 업그레이드

2026-10-26 / Stage1, Stage2, Stage3, StageBoss

## 적용 내용

네 스테이지의 실제 게임 씬에 우주 배경, 금속 패널 바닥, 관측창 형태의 바닥 장식, 구조 프레임, 배관, 기계 설비, 안내등과 장애물을 적용했다. 바닥 관측창은 통행 가능한 구역이다. 기존에 가져온 암석·소행성 환경과 함께 구성했다.

| 스테이지 | 분위기 | 추가 장애물 | 기믹 |
|---|---|---|---|
| Stage1 | 푸른 궤도 채굴 시설 | 충돌 장애물 4개 | 전력 방출 구역 2개, 1회 피해 4 |
| Stage2 | 차가운 극저온 시설 | 충돌 장애물 4개 | 냉각 분출 구역 4개, 이동 속도 72% |
| Stage3 | 주황빛 열처리 시설 | 충돌 장애물 4개 | 열기 분출 구역 4개, 1회 피해 6 |
| StageBoss | 보라색 공허 코어 | 외곽 충돌 장애물 4개 | 코어 에너지 구역 4개, 1회 피해 4 |

위험 구역은 작동 전 2.8초간 경고한다. 구역별 작동 시간을 분산하고 시작 위치를 비웠다. 피해는 최대 초당 1회 시도하며 기존 플레이어 무적 처리를 따른다. 냉각 감속은 구역을 벗어나거나 비활성화되면 해제된다. 기믹은 현재 플레이어에게만 적용된다. 중앙 회피 공간과 우회 경로를 유지했다.

## 확인 결과

- 네 씬 모두 저장 후 경로 검사: 각 8개 대표 경로 통과. 장애물 충돌체와 이동 불가 영역, 시작 위치 안전, 셰이더 오류 여부 확인.
- 실제 Play 모드 Stage1: 경고 중 무피해, 활성 피해 4, 중복 피해 방지, 무적 적용, 구역 밖 무피해, 중지 처리 통과.
- 실제 Play 모드 Stage2: 경고 중 정상 속도, 활성 속도 72%, 퇴장/재진입, 비활성화 시 속도 복구 통과.
- 실제 Play 모드 Stage3: 활성 피해 6과 Stage1과 동일한 피해 제어 검사 통과.
- StageBoss: 실제 씬 로드, 보스 활성 상태, 게임 시간 진행 및 위험 구역 Active 전환 확인. 보스전 전체 승리/패배 시나리오나 난이도 균형 검증은 수행하지 않았다.
- 네 스테이지의 Game 화면과 전체 맵 미리보기를 저장했다. 테스트용 무적은 해제하고 Play 모드를 종료했다.
- 후반 검증 구간에서 새 실행 오류는 없었다. 콘솔에는 이전 Unity QuickInstaller 문자열 변환 오류 및 CLI 상태 조회 호환성 오류 기록이 남아 있다.

## 수정 위치와 복구

아래 경로는 저장소 루트를 기준으로 한다. Unity 6000.3.24f1에서 편집하고 실행 검증했다.

- 실제 씬: `Assets/Scenes/Stage1.unity`, `Stage2.unity`, `Stage3.unity`, `StageBoss.unity`
- 환경 및 기믹 루트: `Deep Space - Environment and Mechanics`
- 코드·셰이더·생성 에셋: `Assets/DeepSpaceUpgrade/`
- 변경 전 씬 백업: `Assets/Scenes/MapBackups/*_BeforeDeepSpaceV2.unity`
- 기믹 조절: 해당 루트 아래 `Telegraphed zone` 오브젝트의 `DeepSpaceHazard`에서 반경, 경고 시간, 작동 시간, 피해, 감속 배율 변경.

검증 도구 `DeepSpaceVerification`은 Editor 폴더에 있어 게임 빌드에 포함되지 않는다. 테스트는 명시적으로 Arm/Check를 호출할 때만 수행한다. 성능 수치는 측정하지 않았으며 플레이 난이도는 실제 플레이 피드백에 따라 추가 조절할 수 있다.
