# 스테이지 템포 개편안

2026-11-04 제안 · 2026-11-05 player 브랜치에 시험 구현 (회의 뒤 수치 조정)

지금은 보스 전까지 전투가 **약 1분 30초**라 긴장감이 약하고, 상위 무기를 얻어도 쓸 시간이 거의 없습니다.
스테이지를 늘리고, 크레딧은 줄이고, 중간에 보급과 정비 기회를 넣으려고 합니다.

## 바뀌는 것

| 항목 | 지금 | 바뀜 |
|---|---|---|
| 스테이지 길이 | 처치 목표 15 · 20 · 25 | **40 · 55 · 70** — 스테이지마다 약 1분 30초 |
| 몬스터 등장 간격 | 3 · 2 · 1초 | **2.4 · 1.6 · 1.2초** (11-06 시험 플레이 뒤 약 25% 더 자주 — 한 번에 1마리, 4번에 1번꼴로 2마리) |
| 크레딧 | 몬스터마다 코인 1 ~ 3 | **30% 줄임** — 처치 수가 늘어도 한 판 총량은 지금의 약 1.7배 |
| 드랍 아이템 (새로) | 코인 · 경험치만 | **자석**: 화면 안 경험치 · 크레딧을 한꺼번에 끌어옴<br>**힐팩**: 체력이 낮을수록 잘 나옴<br>둘 다 낮은 확률 · 스테이지마다 개수 상한 |
| 정비 신호기 (새로) | 정비는 클리어 뒤에만 | 처치 목표 **절반**에서 **맵 무작위 위치**에 생기고 화면에 위치를 표시 — 주우면 그 자리에서 정비창 (스테이지마다 1번) |

## 한 판의 흐름

1. **스테이지 시작** — 몬스터가 몰려오고 자석 · 힐팩이 가끔 떨어진다
2. **처치 목표 절반 → 정비 신호기 등장** — 맵 어딘가에 빛기둥과 함께 생기고, 플레이어 둘레 화살표 · 거리 표시가 방향을 알려 준다
3. **신호기를 주우면 중간 정비** — 시간이 멈추고 정비창이 열린다 (무기 강화 · 상위 무기 바로 갖추기)
4. **남은 절반 처치** — 방금 갖춘 무기 · 상위 무기를 바로 써 본다
5. **클리어** — 레벨업 카드 → 보상 카드 → 정비창 → 다음 스테이지 (지금과 같음)

## 누가 무엇을

| 담당 | 할 일 |
|---|---|
| 스테이지 | 스테이지 데이터의 처치 목표 · 등장 간격 값만 바꿈 |
| 몬스터 · 맵 | 코드 변경 없음 — 아이템은 처치 신호를 받아 떨구고, 신호기 위치는 이동 가능한 바닥에서 고름 |
| 플레이어 | 코인 조정 · 자석 · 힐팩 · 정비 신호기와 위치 표시 · 중간 정비 연결 (player 브랜치 · GameManager 에 중간 정비 함수 하나 추가) |

## 의견 부탁드립니다

- 스테이지 길이(40 · 55 · 70)가 적당한지 — 너무 길거나 짧게 느껴질지
- 크레딧 30% 감소로 정비창이 너무 빡빡해지지 않을지
- 자석 · 힐팩 · 정비 신호기 말고 넣고 싶은 아이템이 있는지
- 맵의 비어 있는 아이템 스포너 자리(8곳)를 이 아이템들에 써도 되는지

수치는 모두 에셋에서 바꿀 수 있습니다 — 자석 · 힐팩 · 신호기는 `Resources/Economy/SupplySettings`, 크레딧 배율은 `EconomySettings` 의 coinMultiplier(0.7), 처치 목표는 스테이지 데이터. 플레이해 보고 함께 조정합니다.
