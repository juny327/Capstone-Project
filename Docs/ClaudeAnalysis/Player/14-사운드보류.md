# 14. 사운드 — 보류

사운드는 **보류**다. 나중에 착수할 때 다시 조사하지 않도록, 지금까지 파악한 현황과 붙일 지점을 남긴다.

관련 문서: [12-탄창장전구현절차](12-탄창장전구현절차.md) (R6) · [13-UI-HUD구현절차](13-UI-HUD구현절차.md)

---

## 1. 지금 상태

프로젝트 전체에서 오디오를 쓰는 곳은 **두 군데뿐**이다.

| 위치 | 용도 |
|---|---|
| `Upgrade/UpgradeCard.cs` | 업그레이드 성공 · 실패음 (`audioSource.PlayOneShot`) |
| `Enemy/Attack/DashAttack.cs` | 돌진 공격 |

즉 **사격 · 장전 · 피격 · 사망 · 서브유닛 · UI 조작이 전부 무음**이다.
`AudioManager` 같은 중앙 관리자도 없고, 볼륨 설정도 없다.

---

## 2. 붙일 지점 (이미 열려 있는 곳)

사운드를 넣을 때 새로 파고들 필요가 없도록, 호출 지점을 미리 정리해 둔다.

### 2-1. 무기

| 시점 | 지점 |
|---|---|
| 발사 | `WeaponBase.Fire()` — 모든 무기가 지나간다 |
| 장전 시작 | `WeaponBase.OnReloadStarted(duration)` |
| 장전 완료 | `WeaponBase.OnReloadFinished()` |
| 장전 취소 | `WeaponBase.OnReloadCanceled()` |
| 탄 떨어짐 | `WeaponBase.CanFire` 가 false 로 바뀌는 지점 (빈 총 "딸깍") |
| 스왑 | `WeaponController.SwapTo()` · `GameEvents.OnWeaponSwapped` |

`WeaponData` 에 `AudioClip fireSound` 같은 필드를 더하면 무기별로 다른 소리를 낼 수 있다.
12번 문서에서 장전 모션을 붙일 때 이미 `OnReloadStarted` 같은 확장 지점을 만들어 뒀다.

### 2-2. 플레이어

| 시점 | 지점 |
|---|---|
| 피격 | `PlayerStats.TakeDamage()` |
| 사망 | `PlayerStats.Die()` · `GameEvents.OnPlayerDeadStart` |
| 회복 | `PlayerStats.AddHP()` |
| 레벨업 | `GameEvents.OnLevelUp` |
| 구르기 | `PlayerMove.StartRoll()` |

### 2-3. UI · 진행

| 시점 | 지점 |
|---|---|
| 카드 선택 | `GameEvents.OnUpgradeSelected` |
| 카드 확인 | `GameEvents.OnUpgradeConfirmed` |
| 스테이지 클리어 | `GameEvents.OnStageClear` |
| 보스 등장 | `GameEvents.OnBossSpawned` |

이벤트가 이미 다 있으므로, 듣는 쪽(`AudioManager`)만 만들면 된다.

## 3. 착수할 때 정해야 할 것

| # | 항목 | 메모 |
|---|---|---|
| S1 | 중앙 관리자 | `AudioManager` 싱글턴 + 풀링 vs 각 객체에 `AudioSource` |
| S2 | 동시 발생 제한 | 기관단총은 초당 8발이다. 같은 소리가 겹치면 귀가 아프다 — 쿨다운이나 보이스 수 제한이 필요 |
| S3 | 볼륨 설정 | `AudioMixer` 그룹(Master · SFX · BGM) + 설정 UI |
| S4 | timeScale 0 | 업그레이드 창은 정지 상태로 뜬다. UI 음은 `ignoreListenerPause` 가 필요할 수 있다 |
| S5 | 에셋 출처 | 무료 SFX 팩 도입 여부. 라이선스 확인 필요 |

> **S2 가 가장 실무적인 함정이다.** 발사음을 `Fire()` 에 그냥 붙이면 SMG 연사에서 같은 클립이 수십 개 겹쳐 소리가 찢어진다.
> 착수 시 제일 먼저 처리할 것.

---

## 4. 왜 보류인가

- 게임 로직(무기 · 레벨업 · 카드 · HUD)이 아직 형태를 잡는 중이라, 지금 붙이면 바뀔 때마다 같이 손봐야 한다
- 사운드 에셋을 아직 고르지 않았다
- 무음이어도 플레이와 테스트에 지장이 없다

**우선순위가 올라가는 시점**: 게임 흐름이 고정되고 빌드를 내보내기 시작할 때.
