### 0-1. 시험하는 길

| 길 | 어떻게 | 언제 쓰나 |
|---|---|---|
| **테스트 룸** | 로비 오른쪽 아래 "테스트 룸" (또는 `Scenes/TestRoom` 을 바로 Play) | 모습 · 동작 · 화력을 빨리 (1 · 2 · 3 · 5장) |

| **실제 판** | 로비에서 무기 고르고 처음부터 | 진화 시점 · 판 전체 밸런스 · 팀원 스킬과 겹침 (5장) |

테스트 룸 지도

```
 원거리 무기     ┌──────────── 북쪽: 금색 = 상위 무기 구역 (11개 — 7 + 4 두 줄 · 간격 5 × 4m) ────────────┐
  [소총]           ① 처형자  ② 프리즘 노바  ③ 거울칼날  ④ 중력 대검  ⑤ 스웜 카빈  ⑥ 회전 기관포  ⑦ 공성포
  [기관단총]       ⑧ 용의 포효  ⑨ 뇌운  ⑩ 태양창  ⑪ 혈검
  [스나이퍼]
  [샷건]
  [전격 소총]          ● 시작                  18m  14m  10m  6m  3m  ▣ 훈련용 해골 (무한 체력 · DPS 측정)
  [충전 레이저]
 근거리 무기
  [검]
  [대검]               [무리 · 모여 있기] [무리 · 둘러싸기]               ▒▒▒ 무리 자리 (모여 있기 9)
  [창]
 └ 서쪽 선반: 원래 무기 9종                                    방 60 × 48m · 바닥 테두리 밖으로 나가면 시작 자리로 ┘
```

- 금색 구역을 밟으면 **원래 무기 → Lv3 → 짝 → 진화** 를 한 번에 한다. 짝이 팀원 스킬이면 그 레벨업 카드까지 준다 (테스트 룸엔 몬스터가 없어 스킬 자체는 쏘지 않는다). 캐릭터가 못 가지는 짝(사수의 에너지 방패)은 "(시험 — 짝 없이)" 로 진화
- 무리 표적 — 체력 **기본 튼튼** (무기 공격력 × 1000, 최소 1만 — 거의 안 죽어 화상 · 경직 · 회복 같은 부가 능력을 오래 본다) · **H 키 — 한 방** (공격력 × 0.9 — 처형자 연쇄 · 불 옮김 · 혈검 혈기처럼 처치로 터지는 것을 볼 때) · 죽으면 2초 뒤 다시 선다 · 무기를 바꿨으면 구역을 다시 밟아 새로 세운다
- **연습 규칙** — 스태미나 무한 · 서브 능력 · 사수 E · 패링 · 구르기 쿨타임 1초 (테스트 룸을 나가면 원래대로)
- **소리**를 볼 때는 설정창(ESC)에서 효과음을 올려 두고, 같은 구역을 몇 번 밟아 진화 · 공격 소리를 비교한다

| 조작 | 키 |
|---|---|
| 이동 · 조준 | WASD · 마우스 (공격은 자동) |
| 무기 바꾸기 · 장전 | Q / 휠 · R |
| 서브 능력 (검사) · 사수 E 능력 | E · F |
| 장비 판 상세 (진화 조건 · 조합식) | Z |
| 무리 체력 튼튼 ↔ 한 방 | H |

- **짝 종류**: 개조 6 (처형자 · 스웜 카빈 · 회전 기관포 · 공성포 · 프리즘 노바 · 태양창) · 서브 능력 1 (거울칼날) · **팀원 스킬 4 — 혈검 ← 흡혈 · 중력 대검 ← 블랙홀 · 뇌운 ← 연쇄 번개 · 용의 포효 ← 파이어볼** (레벨업 카드 — 사수 · 검사 모두 받는다)

## 1. 공통 — 진화 순간 · 모습 · HUD (테스트 룸)

### 1-1. 진화 순간

금색 구역을 밟는다 (아무거나).

- [ ] 화면이 한 번 하얗게 번쩍인다 — 눈이 아프거나 너무 길지 않은가
- [ ] 화면 위 배너 "상위 무기 / 이름" 이 읽히고 1.6초쯤 머문다
- [ ] 플레이어 둘레로 고리 두 겹(테마 색 · 흰색)이 퍼지고 주변 적이 밀려난다
- [ ] 소리가 나고 크기가 적당하다
- [ ] 연출이 조작을 막지 않는다 (움직이고 쏠 수 있다)

### 1-2. 무기 모델 — "확실히 다른 무기" 같은가

| 상위 무기 | 볼 것 | 확인 |
|---|---|---|
| 처형자 | 소총 주황 부분이 **진홍으로 빛난다** · 조금 커졌다 | [ ] |
| 스웜 카빈 | 주황 발광 · **총열 아래 미사일 포드** | [ ] |
| 회전 기관포 | 노랑 발광 · **총구 앞 다총열 6개** — 쏠수록 빨리 돈다 | [ ] |
| 공성포 | 금색 발광 · **큰 포구** · 포탄이 크다 | [ ] |
| 용의 포효 | 주황 빨강 발광 · **총열 아래 연료통 · 노즐 고리** | [ ] |
| 뇌운 | 남색 발광 · **총열 코일 고리 3개** | [ ] |
| 프리즘 노바 | 무지개로 색이 돌며 빛난다 · **총구 둘레에 결정 3개**가 돈다 | [ ] |
| 태양창 | 흰 금색 발광 · **총구 앞 집광 고리**가 돈다 | [ ] |
| 거울칼날 | **파랑 에너지 검** (가드 있는 검 B) | [ ] |
| 혈검 | **붉은 검** (원래 검과 같은 모양의 붉은 검 A) · 붉은 발광 — 대검(같은 모델을 크게)과 헷갈리지 않는가 | [ ] |
| 중력 대검 | **보라 에너지 대검** · 두껍다 | [ ] |

- [ ] 손에 쥔 모양 — 검 · 대검을 손잡이로 쥔다 (칼날을 쥐거나 손에서 떠 있지 않다) · 대검은 왼손이 손잡이에 붙는다
- [ ] 내려찍을 때 칼끝이 바닥 아래로 깊이 들어가지 않는다 · 패링 자세에서 검이 어색하게 꺾이지 않는다
- [ ] 무기를 바꿔 들었다(Q) 다시 들어도 모습이 그대로다
- [ ] 발광이 너무 밝아 하얗게 뭉개지거나 너무 어두워 안 보이지 않는다

### 1-3. 상위 무기를 든 동안

- [ ] **발밑 고리**(테마 색, 숨 쉬듯)가 보인다 — 너무 진해서 거슬리지 않는다 · 다른 무기로 바꾸면 사라진다
- [ ] 근접 상위 무기는 휘두를 때만 **칼끝 궤적**이 남는다 (걸을 때는 안 남는다)
- [ ] 총 상위 무기의 탄이 테마 색이다 (처형자 진홍 …)
- [ ] 혈검은 테마 고리 안쪽에 **혈기 고리**가 하나 더 있다 — 두 고리가 겹쳐 헷갈리지 않는가 (2-10)

### 1-4. HUD · 아이콘

## 2. 무기별 손맛 (테스트 룸)

> 무리 표적: 아래쪽 빨간 구역 — "모여 있기"(9명이 무리 자리에) · "둘러싸기"(8명이 내 둘레). 기본 **튼튼**이라 오래 맞으며 부가 능력을 본다 · 처치로 터지는 것은 **H** (한 방). 해골은 단일 대상 DPS 측정용.
> 각 절 끝 **손맛**은 진화 전 원래 무기와 견줘 본다 — 같은 선반 무기를 밟으면 원래 무기(Lv1)로 돌아간다.

### 사수 — 소총

#### 2-1. ① 처형자 (소총 + 지정사수)

"모여 있기" → **H (한 방)** → 무리 자리 쪽으로 쏜다.

- [ ] 처치한 자리에 **진홍 고리가 안으로 줄어든 뒤 터진다** — "여기 터진다"가 읽힌다
- [ ] 폭발이 이웃으로 **도미노처럼 번진다** (0.08초씩 늦게, 3단까지)
- [ ] 폭발 크기 (반경 2m) 가 화면에서 적당하다 · 연쇄가 겹칠 때 소리 · 흔들림이 과하지 않다
- [ ] 손맛: 진화 전 소총보다 **확실히 시원한가**

#### 2-2. ⑤ 스웜 카빈 (소총 + 3점사)

- [ ] 점사 세 발이 **서로 다른 적**을 쫓아 휘어 날아간다 — 곡선이 보이는가
- [ ] 맞은 자리에 작은 주황 폭발 (반경 1.2m) — 무리에 고르게 퍼지는 느낌
- [ ] 유도탄이 적 둘레를 맴돌기만 하고 안 맞는 일이 없는가
- [ ] 처형자(같은 소총)와 확실히 다른 맛인가 — 처형자 = 처치 연쇄 / 스웜 = 여러 적에 나눠 맞힘

### 사수 — 기관단총

#### 2-3. ⑥ 회전 기관포 (기관단총 + 이중 탄창)

- [ ] 쏘기 시작하면 **2초에 걸쳐 연사가 3배**까지 오른다 · 다총열 회전이 따라 빨라진다
- [ ] **장전이 없다** (계속 쏜다)
- [ ] 멈추면 1초에 걸쳐 느려진다 — 다시 쏠 때 처음부터 오르는 게 답답하지 않은가
- [ ] 최고 연사에서 소리 · 탄이 너무 많아 거슬리지 않은가

### 사수 — 샷건

#### 2-4. ⑦ 공성포 (샷건 + 슬러그)

- [ ] 쏠 때 **총구 충격파 고리** · 흔들림
- [ ] 큰 포탄이 **한 줄을 관통**하며 맞은 적마다 터진다 (반경 1.5m · 2m 밀치기)
- [ ] 사거리 끝(약 15m)에서 **큰 폭발** (반경 3m) — 아무것도 못 맞혀도 터진다
- [ ] 흔들림이 과하지 않은가 (연사 0.9초)

#### 2-5. ⑧ 용의 포효 (샷건 + 파이어볼 — 레벨업 카드)

- [ ] 산탄 대신 **화염 방사** — 정면 6m · 50° 에 불길이 보인다 (밝은 바닥에서도)
- [ ] 맞은 적이 **불탄다** (화상 3초) · 불타다 죽은 적 둘레(2m)로 **불이 옮겨붙는다** (H — 한 방으로 볼 것)
- [ ] 탄창 40 (4초 방사) → 장전 — 리듬이 괜찮은가 · 불 소리가 시끄럽지 않은가
- [ ] 공성포(같은 샷건)와 확실히 다른 맛인가 — 공성포 = 멀리 한 줄 / 용의 포효 = 가까이 부채꼴
- [ ] (실제 판) 짝인 파이어볼 스킬이 같이 날아다녀 "불의 샷건" 다운가

### 사수 — 전격 소총

#### 2-6. ⑨ 뇌운 (전격 소총 + 연쇄 번개 — 레벨업 카드)

- [ ] 장전(R 또는 탄이 떨어짐)하는 동안 **머리 위 먹구름**
- [ ] 구름에서 주변 8m 적에게 **낙뢰가 초당 4번** (경직 0.3초) — 장전 시간이 오히려 공격 시간
- [ ] 장전이 끝나면 구름 · 낙뢰가 멈춘다 · (방전 개조를 달았으면 장전 시작 순간의 방전도 그대로 — 짝은 아니다)
- [ ] (실제 판) 짝인 연쇄 번개 · 팀원 전격 샷과 같이 터질 때 헷갈리거나 너무 어지럽지 않은가

### 사수 — 충전 레이저

#### 2-7. ② 프리즘 노바 (충전 레이저 + 분광 프리즘)

"모여 있기" 앞(5 ~ 6m)에서 쏜다. 한 발 = **① 분산 1초 → ② 수렴 0.3초 → ③ 방사 2초**.

- [ ] ① 결정 3개가 **빨강 · 초록 · 파랑 빛**이 되어 앞쪽 적 사이를 튕긴다 — 빛이 보이는가 · 하얗게 날아가지 않는가 · 뒤쪽 적은 노리지 않는다 (앞 140°)
- [ ] ② 빛이 총구로 빨려 들어오며 **흰 섬광** — "이제 온다"가 읽히는가
- [ ] ③ 세 색이 감긴 **굵은 빔이 2초** — 커서를 돌리면 천천히 따라온다 (초당 120°) · 휘둘러 쓸어 담는 맛
- [ ] **🔊 2026-10-13** — ③ 빔이 켜지는 순간 **저음 "두우우웅"** (낮은 폭발 + 낮게 울리는 종) 이 빔 소리 아래에 깔린다 · 묵직한가 · 너무 크거나 다른 소리를 덮지 않는가 · 빔이 끝난 뒤 조금 남는 울림이 어색하지 않은가
- [ ] 한 주기(약 3.3초) 동안 다음 발이 안 나가고, 끝나면 충전(2.2초)부터 — 리듬이 답답하지 않은가 · 탄창 3발 → 장전
- [ ] 빔 · 빛이 화려해서 **적 탄 · 적이 안 보이는 순간**이 없는가

#### 2-8. ⑩ 태양창 (충전 레이저 + 과충전)

- [ ] 충전이 차면 **0.8초 더 모은다** — 총구에 빛 고리가 안으로 모인다
- [ ] 모으는 동안 **바닥 예고선이 앞으로 뻗어 간다 (10m → 32m)** · 끝점 고리 — "모을수록 멀리"가 읽히는가 · 커서를 돌리면 따라 돈다
- [ ] 다 모으면 **굵은 흰 금빛 기둥 한 방** — 줄 위 적 전부 · 화상 · **바닥 그을음** · 큰 흔들림
- [ ] 한 발 주기(충전 약 2.3초 + 모으기 0.8초)가 답답하지 않은가
- [ ] 프리즘 노바(같은 충전 레이저 — 쭉 쏘는 빔)와 확실히 다른 맛인가

### 검사 — 검

#### 2-9. ③ 거울칼날 (검 + 에너지 방패)

"모여 있기" 앞에서 휘두른다. 탄 되돌리기는 **실제 스테이지의 원거리 몬스터(C)** 로 본다.

- [ ] **네 번째 휘두르기마다** 초승달 검기 3개가 부채꼴로 날아간다 — "4번째" 리듬이 느껴지는가
- [ ] 검기 크기 · 밝기가 보기 좋다 · 사거리 8m 까지 날아가 멀리 있는 적을 맞힌다
- [ ] (스테이지) 휘두를 때 정면의 몬스터 탄이 **되돌아간다** (청록) — 패링(검사 회피 키)의 반사와 겹쳐 어색하지 않은가
- [ ] **🔊 2026-10-13 날카로운 칼 + 마법 에너지**:
  - 휘두를 때마다 금속 날이 스치는 **"슈잉"** 위에 맑은 **반짝임**(유리 · 고음)이 한 겹 — 날카롭고 마법 같은가 · 빨리 연달아 휘두를 때 시끄럽지 않은가
  - 검기가 날아갈 때 높은 에너지 **"위잉—"**
  - 탄을 되돌릴 때 높게 친 종 같은 **"챙"** + 유리 울림

#### 2-10. ⑪ 혈검 (검 + 흡혈 — 레벨업 카드)

> 테스트 룸 ⑪ 을 밟으면 흡혈 카드까지 채워 진화한다 (사수도). 혈기는 **처치**로 쌓이니 **H (한 방)** 로 "모여 있기" · "둘러싸기" 를 빠르게 쓰러뜨린다.

- [ ] **발밑 혈기 고리** — 처치할 때마다 붉은 호가 카메라 쪽(아래)부터 찬다 · HP 가 가득이면 두 배로 · 잘 보이는가
- [ ] 흡혈 1장 기준 처치 약 7번(HP 가득이면 4번)에 가득 — 너무 빠르거나 느리지 않은가
- [ ] **폭주** (고리가 가득) — 퍼지는 붉은 고리 두 겹 · 낮은 굉음 · 6초 동안 휘두르기가 **빨라지고(×1.5) 1m 길어진다** · 고리가 맥박처럼 뛴다
- [ ] **🩸 혈풍 난무 (2026-10-13 — 엘든링 말레니아 "물새난격"처럼)**:
  - 폭주가 시작되는 순간 **0.7초 동안 붉은 검격 12줄**이 쏟아지고, 폭주가 끝날 때까지 **0.8초(±25%)마다 6줄씩** 계속 몰아친다
  - 검격마다 **방향(360° 무작위) · 크기 · 길이 · 사선 기울기(±55°) · 높이**가 다르다 — 칼로 사방을 난도질하는 흐름으로 보이는가 · 너무 규칙적이거나 너무 어지럽지 않은가
  - 굵은 붉은 호 + 안쪽 밝은 호 · 피 방울 줄기 · 칼바람 + 젖은 피 소리 · 반경 4m 안 그 방향 적을 벤다 (줄마다 공격력 × 0.4)
  - 앞뿐 아니라 **뒤 · 옆에 있는 적도** 베인다 ("둘러싸기" 로 볼 것)
  - 날아가는 초승달(거울칼날)이 아니라 **내 둘레를 베는 호** 로 보이는가 · 화면을 너무 덮지 않는가 · 적 · 몬스터 탄이 안 보이지 않는가
  - 검격으로 쓰러뜨려도 흡혈 회복 · 폭주 연장이 된다 · 폭주가 끝나면 바로 멈춘다
- [ ] 폭주 중 벨 때 적에게서 **피 줄기**가 날아오며 HP 가 찬다 — 한 명이면 초당 1 남짓, 무리를 베면 초당 최대 8
- [ ] 폭주 중 처치하면 조금씩 길어진다 (최대 10초) · 끝나면 속도 · 길이가 돌아오고 고리가 비어 다시 찬다
- [ ] 다른 무기로 바꾸면 폭주가 끝난다 (혈기는 남는다)
- [ ] (실제 판) 흡혈 원래 동작(처치당 +3 회복)도 그대로 · 흡혈 카드를 더 고르면 처치당 혈기가 더 오른다 · 보스를 때려도 혈기가 조금씩 (+2)
- [ ] 거울칼날(같은 검)과 확실히 다른 맛인가 — 거울칼날 = 탄 되돌리기 · 날아가는 검기 / 혈검 = 몰아치기 · 버티기 · 사방 무작위 피 검격

### 검사 — 대검

#### 2-11. ④ 중력 대검 (대검 + 블랙홀 — 레벨업 카드)

"모여 있기" 또는 "둘러싸기" 앞에서 휘두른다.

- [ ] **내려찍기**(세로베기) 때 앞 3m 바닥에 **보라 소용돌이** — 가로베기 때는 안 생긴다

- [ ] **스킬 짝 구역(혈검 · 중력 대검 · 뇌운 · 용의 포효)** 은 사수 · 검사 모두 그 레벨업 카드(흡혈 · 블랙홀 · 연쇄 번개 · 파이어볼)까지 채워 진화한다
- [ ] 이미 진화한 구역을 다시 밟으면 그 상위 무기를 꺼내 든다 · 선반의 원래 무기를 밟으면 원래 무기(Lv1)로
- [ ] 보관한 10종(다중 표적 · 천공창 포함) 구역은 없다
- [ ] 무리 표적 처치 · 누적 피해 · 최근 5초 DPS 줄이 맞게 오른다 · 해골 측정 · [측정 초기화] · [룸 초기화] · [로비로]
- [ ] **무리 체력** — 처음엔 튼튼(거의 안 죽음 · HUD "무리 튼튼") → 화상 · 경직 · 끌기 · 혈검 회복을 오래 볼 수 있다 · **H** 를 누르면 한 방으로 다시 선다(HUD "무리 한 방") → 처치로 터지는 효과 확인 · 다시 H 로 튼튼
- [ ] `Tools / 상위 무기 시험` 창 — 11종 목록 · 상태("진화함 / 진화 가능 / Lv1/3 · 짝 없음") · 스킬 짝은 "흡혈 (레벨업 카드)" 처럼 · [조건] · [진화] · [들기] 가 동작한다

## 4. 실제 판 흐름 — 보상 카드 · 정비 창 (스테이지)

> 처음부터 모으기는 오래 걸리므로, Stage1 에서 `Tools / 상위 무기 시험` 의 **[조건]** 으로 조건만 채우고 시작해도 된다 (스킬 짝이면 그 스킬 카드까지 준다 — 그 판에서 스킬이 실제로 돈다).

### 4-1. 보상 카드 · 정비 창

- [ ] 조건을 채우고 클리어 → 보상 카드 중 한 장이 **"상위 무기 — 이름"** · 설명 · 그림
- [ ] 카드를 고르면 정비 창으로 넘어가고, **다음 스테이지가 시작될 때** 진화 연출이 나온다 (정비 중에는 안 나온다 — 의도)
- [ ] 다른 카드를 고르면 진화하지 않고 다음 보상 카드 · 정비 창에 다시 나온다
- [ ] 정비 창 무기 줄 **맨 앞에 "진화" 카드 (백금색 · 0 코인)** — 다른 무기 카드가 가려져도 불편하지 않은가
- [ ] 진화한 뒤 개조 칸이 잠기고(사수) 다른 부위 부착물은 살 수 있다 · 진화한 무기는 "강화" · "새 무기" 에 안 나온다

### 4-2. 짝마다 얻는 길

- [ ] 사수 (개조) — 무기 Lv3 + 정비 창 장비 줄에서 그 개조를 사서 단다 (처형자 · 스웜 카빈 · 회전 기관포 · 공성포 · 프리즘 노바 · 태양창)
- [ ] 검사 (서브 능력) — 검 Lv3 + 정비 창에서 에너지 방패 → 거울칼날 · 진화 뒤에도 E · F · 패링이 그대로
- [ ] **팀원 스킬 짝 (레벨업 카드)** — 혈검 = 검 + 흡혈 · 중력 대검 = 대검 + 블랙홀 · 뇌운 = 전격 소총 + 연쇄 번개 · 용의 포효 = 샷건 + 파이어볼. 무기 Lv3 + 레벨업 카드에서 그 스킬을 고르면 다음 보상 카드 · 정비 창에 진화. 레벨업 카드는 11장 중 3장이라 원하는 스킬을 만나기 어렵지 않은가
- [ ] 스킬 짝 무기는 진화 뒤에도 그 스킬이 따로 계속 돈다 — 같은 계열 이펙트가 겹쳐 보기 좋은가 · 너무 어지럽지 않은가

## 5. 밸런스 (가장 중요)

### 5-1. 진화 시점 (실제 판 처음부터)

| 볼 것 | 메모 |
|---|---|
| 주력 무기가 **Lv3** 에 닿은 때 (Stage ? 클리어 뒤) | |
| 짝(개조 · 서브 능력 · 스킬 카드)을 손에 넣은 때 | |
| **진화한 때** · 그 뒤 상위 무기로 싸운 시간 | |
| 보스전 길이 — 상위 무기 있을 때 ___초 / 없을 때 ___초 (목표: 있을 때 60 ~ 90초) | |

- [ ] 진화가 너무 이르지(Stage 1 ~ 2) · 늦지(보스 직전) 않은가
- [ ] 개조 카드가 정비 창 3칸 무작위에 잘 안 나와 사수 진화가 막히지 않는가
- [ ] 스나이퍼 · 창으로 시작하면 진화가 없는데 끝까지 할 만한가 (새 상위 무기를 붙일지 정할 근거)

### 5-2. 11종 세기 비교 (테스트 룸)

해골(단일 대상 — 왼쪽 위 "최근 5초 DPS") · "모여 있기" 9명 처치 시간(**H — 한 방이 아니라 튼튼일 때는 누적 피해**)으로 잰다. 같은 줄의 두 무기(소총 · 샷건 · 충전 레이저 · 검)는 서로 견줘 본다.

| 상위 무기 | 해골 5초 DPS | 모여 있기 누적 피해 (10초) | 느낌 (세다 / 알맞다 / 약하다) |
|---|---|---|---|
| ① 처형자 | | | |
| ⑤ 스웜 카빈 | | | |
| ⑥ 회전 기관포 | | | |

- [ ] 진화 직후 **"확 세졌다"** 가 느껴지는가 (목표: 같은 무기 대비 단일 ×2 · 무리 ×4)
- [ ] 하나만 압도적이지 않은가 (그것만 고르게 된다) · 너무 약한 것은 없는가
- [ ] 너무 세서 Stage 3 · 보스가 시시하지 않은가

### 5-3. 성능 · 가독성 (Stage 3 · 적이 많을 때)

- [ ] 처형자 연쇄 · 프리즘 노바 · 용의 포효 · 뇌운 · 중력장 · 혈풍 난무에서 **프레임이 떨어지지 않는가**
- [ ] 이펙트가 겹쳐 **적 · 몬스터 탄이 안 보이는** 순간이 없는가 (팀원 스킬 이펙트와 같이)
- [ ] 소리가 겹쳐 시끄럽지 않은가 (프리즘 저음 · 중력 대검 쿵 · 혈풍 난무 칼바람이 연달아)
- [ ] 화면 흔들림이 겹쳐 멀미 나지 않는가
