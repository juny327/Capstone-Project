## 0. 시작하기 전에

### 0-1. 테스트하는 세 가지 길

| 길 | 어떻게 | 좋은 것 | 못 하는 것 |
|---|---|---|---|
| **테스트 룸** | 로비에서 무기를 골라 캐릭터를 정한 뒤 오른쪽 아래 "테스트 룸" (또는 `Scenes/TestRoom` 을 바로 Play) | 무기 · 상위 무기 · 작은 조합을 빨리 바꿔 보기, DPS 측정, **연습 규칙**(스태미나 무한 · 쿨타임 1초) | 적 AI 가 없다 (밀치기 · 끌기 · 패링 · 몬스터 탄은 무리 표적 정도만), 일반 부착물 · 서브 능력 변형을 줄 곳이 없다 |
| **Tools 창** (Play 중) | `Tools / 주무기 지급` = `Tools / 상위 무기 시험` (같은 창) | 스테이지 · 테스트 룸 어디서나 무기 받기, 상위 무기 [조건] · [진화], 작은 조합 [갖추기] | — |
| **실제 판** | 로비에서 무기를 골라 처음부터 | 적 AI · 몬스터 탄 · 보상 카드 · 정비 창 · 재화 · 밸런스 | 원하는 장비를 바로 얻기 어렵다 (Tools 창으로 보충) |

### 0-2. 조작

| 조작 | 키 |
|---|---|
| 이동 · 달리기 | WASD · Shift (스태미나) |
| 조준 · 공격 | 마우스 방향 · **자동 공격** (사거리 안에 적이 있으면 쏜다 / 벤다) |
| 회피 | 우클릭 — 사수 구르기 / 검사 패링 |
| 장전 · 무기 바꾸기 · 점프 | R · Q 또는 휠 · Space |
| 사수 E | 지금 든 총의 **하부 부착물 능력** (유탄 · 총검 돌격 · 충격 방출기) |
| 검사 E · F | 서브 능력 1 · 2칸 (먼저 얻은 것이 E) — 그랩은 누르기, 방패는 누르고 있기 |
| Z | 장비 HUD 상세 켜기 / 끄기 (효과 한 줄 · 조합식 판 계속 보이기) — 다음 실행에도 기억 |
| ESC | 설정창 (음량) |

### 0-3. 테스트 룸 지도

```
 원거리 무기     ┌───────────── 북쪽: 금색 = 상위 무기 구역 (7개씩 3줄 · 간격 5 × 4m) ─────────────┐
  [소총]           [처형자] [프리즘 노바] [거울칼날] [중력 대검] [스웜 카빈] [회전 기관포] [파편 폭풍]
  [기관단총]       [공성포] [용의 포효] [레일캐논] [다중 표적] [폭풍 코일] [뇌운]       [태양창]
  [스나이퍼]       [사슬검] [성채 대검] [천공창]   [팔랑크스] [폭격 편대] [위성 방벽]
  [샷건]
  [전격 소총]          ● 시작                  18m  14m  10m  6m  3m  ▣ 훈련용 해골 (무한 체력)
  [충전 레이저]
 근거리 무기
  [검]
  [대검]               [무리 · 모여 있기] [무리 · 둘러싸기]               ▒▒▒ 무리 자리 (모여 있기 9)
  [창]
 └ 서쪽 선반: 간격 4.5m                                         방 60 × 48m · 바닥 테두리 밖으로 나가면 시작 자리로 ┘
```

- **2026-10-12 넓혔다** — 방 36 × 26 → 60 × 48m, 선반 간격 2.6 → 4.5m (발판 사이 빈틈 약 2.9m), 금색 구역 간격 5 × 4m. 발판 사이로 지나가도 옆 무기 · 구역을 밟지 않는다
- 금색 구역은 밟으면 원래 무기 → Lv3 → 짝 → 진화
- 무리 표적: 체력 = 손에 든 무기 공격력 × 0.9 (한 방에 쓰러져 연쇄 · 광역이 보인다) · 죽으면 2초 뒤 다시 선다 · 무기를 바꿨으면 다시 세운다
- **연습 규칙**: 스태미나 무한 · 서브 능력 · 사수 E · 패링 · 구르기 쿨타임 1초 (테스트 룸을 나가면 원래대로)
- 드론은 선반에 없다 — 폭격 편대 · 위성 방벽 구역을 밟으면 드론까지 채워 진화한다

### 0-4. Tools 창 (Play 중)

| 칸 | 버튼 | 하는 일 |
|---|---|---|
| 총 · 근접 | [받기] / [들기] | 무기 받기 (칸이 차면 손에 든 무기와 바꾼다 — 바뀐 무기의 레벨 · 부착물은 사라짐). 캐릭터 제한은 무시 |
| 상위 무기 | [조건] | 원래 무기 · 최대 레벨 · 짝 장비만 채운다 → 실제 판의 **보상 카드 · 정비 창 진화 흐름**을 볼 때 |
| | [진화] / [들기] | 바로 진화 (연출 포함) / 이미 진화했으면 꺼내 든다 |
| 작은 조합 | [갖추기] | 짝 장비를 단다 — 사수: 손에 든 총(안 맞으면 맞는 총)에 하부 + 탄 · 검사: 서브 능력 둘 (변형 포함). 캐릭터가 못 가지는 조합은 이유와 함께 거절 |

### 0-5. 자동 테스트가 이미 확인한 것 (다시 안 봐도 된다)

- 무기 수치 · 장전 규칙 · 레벨업 효과 · 최대 레벨 3, 부착물 32종 수치 · 조건 · 명중 효과 · E 능력, 서브 능력 변형 8종 동작
- 상위 무기 20종 진화 조건 · 넘겨받는 것 · 고유 동작 수치, 보상 카드 진화 확정 · 정비 창 맨 앞
- 작은 조합 7종 켜지는 조건 · 효과, 조합 안내 HUD 내용 (무기마다 짝 · 상위 무기 · 가짐 · 진화 가능), 알림 · 장비 HUD 표시
- 테스트 룸 장면 (121 항목) · 연습 규칙 · 이벤트 겹침 버그 수정 (레벨업 · 클리어 · 사망)

> 그래서 아래는 **"잘 보이나 · 재미있나 · 너무 세거나 약하지 않나 · 어색하지 않나 · 흐름이 막히지 않나"** 를 본다.

### 0-7. 적는 법

- 각 항목 `[ ]` 를 `[x]` 로, 이상하면 옆에 한 줄 메모 (예: "유탄이 커서보다 짧게 떨어짐")
- 숫자만 바꾸면 되는 것은 **15장 "고칠 곳"** 에 어느 에셋인지 있다. 메모를 주면 그대로 고친다
- 14장 "알려진 이슈"에 있는 것은 버그가 아니다 (아직 안 했거나 알고 있는 것)

## 1. 로비 · 캐릭터 선택

- [ ] 로비 좌우 두 영역 — **무기를 누르면 그 무기의 캐릭터**로 정해진다 (사수: 소총 · 기관단총 · 스나이퍼 · 샷건 · 전격 소총 · 충전 레이저 / 검사: 검 · 대검 · 창)
- [ ] 고른 무기를 들고 Stage1 이 시작된다 · 외형은 같고 무기로 구분된다
- [ ] 검사로 시작하면 체력 140 (사수 100) · 조금 빠르다 (×1.1) · 받는 피해 ×0.85 — 체감이 나는가
- [ ] 검사는 총을, 사수는 근접 무기를 보상 · 정비 창에서 만나지 않는다 (교차 획득 불가)
- [ ] "테스트 룸" · "설정" 버튼이 동작한다 · 로비 배경음

## 2. 이동 · 회피 · 기본 HUD

### 2-1. 이동 · 스태미나

- [ ] 걷기 · 달리기(Shift) — 달리면 스태미나가 약 4초에 바닥나고, 바닥나면 바가 붉어지며 25% 찰 때까지 다시 못 달린다 (0 근처에서 떨리지 않는다)
- [ ] 멈춘 뒤 0.5초 지나서 회복 — 걸을 때보다 서 있을 때 빨리 찬다
- [ ] 슬로우 · 스턴(몬스터)이 끝나면 원래 속도로 돌아온다

### 2-2. 구르기 (사수)

- [ ] 우클릭 — 마우스 쪽이 아니라 **이동 방향**으로 4m (이동 입력이 없으면 뒤로 백스텝) · 구르는 동안 무적 · 다시 쓰기까지 4초 (HUD 아이콘 덮개)
- [ ] 구르기 직전에 눌러도 0.15초 안이면 이어서 나간다 (입력 버퍼)
- [ ] 장전 중에 구르면 장전이 취소된다 (탄약은 그대로)

### 2-3. 패링 (검사) — 실제 판에서 (몬스터 · 몬스터 탄이 필요)

- [ ] 우클릭 → 0.2초 판정 — 주변 2m 전체 + 커서 쪽 5m 부채꼴의 적이 **3m 밀려나고 1초 멈춘다** · 0.6초 무적
- [ ] 원거리 몬스터(C, 주황 구체)의 탄을 **칼면 거울 반사**로 되돌린다 — 정면이면 곧장, 비스듬하면 반대쪽 비스듬히 · 되돌린 탄이 몬스터를 맞힌다
- [ ] 히트 스톱(아주 잠깐 멈춤) · 금속음 + "팅~" 여운 · 주황 불똥 — 시원한가 · 적이 많을 때 불똥이 과하지 않은가
- [ ] 헛치면 전용 소리 + HUD 아이콘이 붉다 · 쿨타임 5초 (헛쳐도 같다) — 너무 길지 않은가
- [ ] 보스에게는 밀치기 없이 무적만 · 보스 탄은 못 쳐낸다
- [ ] 무기별 자세 — 검 맞받아치기, 대검 · 창 양손 방어

### 2-4. HUD

| 자리 | 볼 것 | 확인 |
|---|---|---|
| 왼쪽 아래 | 무기 슬롯 4칸 (든 무기 노란 테두리 · 아이콘 · 이름 · 레벨, 상위 무기 ★ / 진화 가능 "진화!") · 구르기 / 패링 아이콘 · 스태미나 바 · E · F 능력 아이콘(쿨타임 숫자 · 방패 내구도) | [ ] |
| 오른쪽 아래 | 탄약 `24 / 30` + 총알 10칸 (근접 · 드론 · 탄창 무한이면 숨는다) · 그 위 **장비 판** (총: 부착물 6칸 / 검사: 서브 능력 E · F) | [ ] |
| 오른쪽 위 | 크레딧 (스테이지에서만) | [ ] |
| 왼쪽 가운데 | **조합식 판** (주무기를 얻을 때 6초 — 8장) | [ ] |
| 화면 위 | 상위 무기 진화 배너 · **작은 조합 알림** | [ ] |

- [ ] Z 를 누르면 장비 판에 효과 한 줄이 붙고 다시 누르면 접힌다 · 다음 실행에도 기억
- [ ] 정비 창이 열리면 장비 판 · 조합식 판이 숨는다 · 사망하면 숨는다

## 4. 검사 — 근접 공격

- [ ] 사거리 + 0.5m 안 **정면 부채꼴**에 적이 있을 때만 휘두른다 (허공에 휘두르지 않는다)
- [ ] 기본 공격과 **양손 내려찍기**가 섞인다 · 같은 모션이 3번 넘게 이어지지 않는다
- [ ] 검 한손 가로베기 / 대검 양손 가로베기 / 창 양손 찌르기 — 모션이 무기에 어울리는가
- [ ] 칼끝이 사거리 끝 근처에 닿아 보인다 (검 2.3 · 대검 3.5 · 창 5m) · 내려찍을 때 칼끝이 바닥 아래로 깊이 안 들어간다

- [ ] 무기를 바꿔 들 때 자세 · 모델이 바로 바뀐다

## 5. 사수 — 총기 부착물 (32종)

> 얻는 곳: **실제 판 정비 창 장비 줄** (부착물 3칸 무작위 · 새로고침), 보상 카드 4종. 테스트 룸은 작은 조합 [갖추기] · 상위 무기 구역(개조)만 준다.

### 5-1. 사고 다는 흐름

- [ ] 부착물 카드를 누르면 **장착할 총을 고른다** — 달 수 있는 총만 밝아지고, 마우스를 올리면 바뀌는 수치("탄창 30 → 45")
- [ ] 우클릭 · 취소 버튼 · 같은 카드 다시 누르기 = 취소 (돈은 그대로) · 달 수 있는 총이 하나뿐이고 그 칸이 비면 바로 산다
- [ ] 같은 부위를 다시 달면 **교체** (이전 것은 사라진다) · 미리보기에 교체 전후
- [ ] 보상 카드 — 레이저 조준기 · 수직 손잡이 · 확장 탄창 · 소이탄을 "스나이퍼 — 레이저 조준기" 처럼 그 칸이 빈 총으로 제시
- [ ] 장비 판 6줄 (조준경 · 총구 · 하부 · 탄창 · 탄 · 개조) — 등급 색 테두리 (기본 초록 · 균형 노랑 · 개조 빨강)
- [ ] 32종 중 원하는 것을 만나기 어렵지 않은가 (정비 창 3칸 무작위 — 14장)

### 5-2. 수치형 · 신호

### 5-3. 하부 E 능력 (그 총을 들면 E)

## 6. 검사 — 서브 능력 (그랩 훅 · 에너지 방패)

> 얻는 곳: 실제 판 정비 창 장비 줄 (새 능력 · 레벨업 변형) · 보상 카드 (새 능력만). 테스트 룸은 상위 무기 구역 · 작은 조합 [갖추기]로 그랩 · 방패 · 반사판만 준다.

### 6-1. 기본

| | 그랩 훅 (E/F 누르기) | 에너지 방패 (E/F 누르고 있기) |
|---|---|---|
| 볼 것 | 왼손 와이어 8m · **처음 닿은 적**을 내 앞 1.5m 로 끌어와 멈춤 · 맞히면 7초, 빗나가면 2초 | 몸 앞 반투명 방패 — **정면 120°** 피해를 막는다 · 이동 ×0.6 · 자동 공격 멈춤 |
| 예외 | 자폭 몬스터는 끌지 않고 멈춤만 · **보스에게는 내가 끌려간다** | 내구도 50 — 0 이면 깨져 4초 못 든다 · 내리면 2초 뒤 회복 · 0.3초 이상 들고 떼면 **밀치기** |
| 확인 | [ ] 와이어가 잘 보인다 · 끌려오는 맛 | [ ] 방패면이 잘 보인다 · 막을 때 불똥 · 소리 |

- [ ] 처음 얻은 능력이 E, 두 번째가 F · 아이콘 · 장비 판 줄
- [ ] 한 번에 하나 — 방패를 든 채 다른 능력 · 패링을 누르면 방패를 내리고 그쪽을 쓴다 (**예외: 작은 조합 "방패 받기"가 켜지면 방패를 든 채 그랩** — 8장)
- [ ] 보상 카드 · 정비 창(시간이 멈춘 동안)에는 능력 키가 먹지 않는다

### 6-2. 레벨업 변형 (트라이포드 — Lv2 · Lv3 에서 A / B 중 하나)

- [ ] 정비 창에 같은 능력의 A · B 두 장이 나란히 ("에너지 방패 — 반사판 [Lv.1 → 2 · A]") · 하나를 사면 다른 쪽은 "다른 변형을 골랐다"로 닫힌다
- [ ] 장비 판 Z 상세에 "변형: 작살 · 추격"

| 능력 | 변형 | 볼 것 | 확인 |
|---|---|---|---|
| 그랩 Lv2 | A 작살 / B 충격 와이어 | 30° 안 최대 2명 더 끌기 / 경직 +1초 · 피해 ×2 | [ ] |
| 그랩 Lv3 | A 넘기기 / B 추격 | 끌어온 적을 내 뒤 3m 로 / **내가 날아가** 도착해서 벤다 | [ ] |
| 방패 Lv2 | A 반사판 / B 강화 방벽 | 들고 있으면 정면 몬스터 탄이 되돌아간다 / 내구도 90 · 회복 ×1.5 | [ ] |
| 방패 Lv3 | A 방패 돌진 / B 방패 던지기 | 떼면 5m 돌진 · 부딪힌 적 밀침 / 떼면 방패가 날아가 꿰뚫고 돌아온다 (돌아올 때까지 못 든다) | [ ] |

- [ ] 변형마다 가격 · 체감이 맞는가 · 고르는 재미가 있나 (전용 모션은 아직 — 14장)

## 7. 상위 무기 (진화) — 20종

> 무기마다 자세한 확인 항목 · 수치 조정표는 [상위무기-인게임-테스트.md](상위무기-인게임-테스트.md). 여기는 공통 흐름 + 한 줄 요약.

### 7-1. 조건 · 받는 법

- [ ] 조건 = **무기 최대 레벨(Lv3) + 짝 장비가 있기만** (사수: 그 총에 개조 / 검사: 서브 능력 / 폭격 편대: 가진 총 하나에 유탄 발사기)
- [ ] 조건을 채우면 무기 칸 글자 "진화!" · 장비 판 머리글 "· 진화 가능" · 조합식 판 "진화 가능 — 처형자"
- [ ] **보상 카드**에 "상위 무기 — 처형자" 카드가 반드시 한 장 · 다른 카드를 고르면 다음 기회에 다시 나온다
- [ ] **정비 창** 무기 줄 맨 앞에 백금색 진화 카드 (0 코인)
- [ ] 진화는 **시간이 다시 흐를 때** 연출된다 (카드 · 정비 중에는 안 나온다 — 의도)

### 7-2. 진화 순간 · 진화 뒤

- [ ] 화면 번쩍 · 배너 "상위 무기 / 이름" 1.6초 · 고리 두 겹 · 주변 적 밀쳐내기 · 흔들림 · 소리 — 조작은 막지 않는다
- [ ] 같은 칸 · Lv3 · 부착물 · E 능력(쿨타임) 그대로 · **개조 칸 잠김** · 원래 무기는 다시 안 판다
- [ ] 무기 모델이 확실히 달라 보인다 (발광 · 부속 · 새 칼 모델) · 발밑에 테마 색 고리 · 탄이 테마 색 · 아이콘 ★
- [ ] 손에 쥔 모양 — 검 · 대검 · 지팡이 · 할버드를 제대로 쥐고, 머리(날 · 결정)가 앞을 본다

### 7-3. 20종 한 줄 요약 (테스트 룸 금색 구역에서 하나씩)

| 파편 폭풍 | 기관단총 + 난사 | 맞을 때마다 불꽃 선 2줄이 옆 적으로 | [ ] |
| 공성포 | 샷건 + 슬러그 | 큰 포탄이 한 줄을 관통하며 연속 폭발 · 사거리 끝 큰 폭발 | [ ] |

## 8. 작은 조합 7종 · 조합 안내 HUD

### 8-1. 조합 안내 HUD (주무기를 얻으면 조합식)

- [ ] 판 시작 · 새 주무기를 얻을 때 **왼쪽 가운데**에 6초 — "[짝 그림] 짝 이름 · 어디서 얻는지 → [상위 무기 그림] 이름"
- [ ] 무기마다 맞다 — 검: 에너지 방패 → 거울칼날 · 그랩 훅 → 사슬검 / 소총: 지정사수 → 처형자 · 3점사 → 스웜 카빈 …
- [ ] 짝을 가지면 "가짐"(초록) · 최대 레벨까지 채우면 "진화 가능 — 이름 (보상 카드 · 정비 창)"
- [ ] 캐릭터가 못 가지는 짝은 안 나온다 — 검사의 드론은 위성 방벽만, 사수의 드론은 폭격 편대만
- [ ] 무기를 바꿔 들거나 다음 스테이지로 가도 다시 뜨지 않는다 · 연달아 얻으면 2초 뒤 새 무기로 바뀐다
- [ ] **Z 상세**를 켜 두면 지금 든 무기의 조합식이 계속 보인다
- [ ] 보상 카드로 무기를 얻으면 카드가 닫히고 시간이 흐를 때 뜬다
- [ ] 조합식 판이 전투를 가리거나 다른 HUD 와 겹치지 않나 · 6초가 적당한가

### 8-2. 작은 조합 7종 (장비 둘이 만나면 자동)

공통
- [ ] 켜지는 순간 **화면 위(체력바 · 처치 수 아래)** 에 "작은 조합 — 이름 / 조건 — 효과" 2.6초 · 진화 배너가 뜨는 동안은 기다렸다 나온다
- [ ] 장비 판의 두 부품 줄 이름 옆에 색 "조합" · Z 상세면 효과 줄 앞에 "네이팜 유탄: …"
- [ ] 부품 하나를 바꾸면 꺼진다 · 다른 조합이 켜지면 그 알림

| 조합 | 조건 | 볼 것 | 확인 |
|---|---|---|---|
| 네이팜 유탄 | 같은 총에 유탄 발사기 + 소이탄 | E → 착탄 자리 3초 **불바다** · 걸어 들어온 적도 탄다 | [ ] |
| EMP 유탄 | 유탄 발사기 + 전격탄 | 폭발에 맞은 적 **1.5초 멈춤** · 전격 줄기 | [ ] |
| 폭파 돌격 | 총검 돌격 + 폭발탄 | 돌진이 끝난 자리 앞에서 **폭발** | [ ] |
| 테슬라 노바 | 충격 방출기 + 전격탄 | 밀쳐낸 적 모두에게 전격 · 조금 더 멈춤 | [ ] |
| 화염 고리 | 충격 방출기 + 소이탄 | 밀쳐낸 적 모두 4초 화상 · 불 고리 | [ ] |
| 방패 받기 | 그랩 훅 + 에너지 방패 | 방패를 든 채 그랩 — **방패가 안 내려간다** · 끌려온 적이 방패에 부딪혀 피해 · 오래 멈춤 | [ ] |
| 거울 패링 | 패링 + 방패 Lv2 A(반사판) | (실제 판) 패링으로 되돌린 탄이 **두 배** · 청록 고리 | [ ] |

## 9. 판 흐름 — 스테이지 · 보상 · 정비 · 재화

### 9-1. 흐름

```
로비 → Stage1 (처치 15) → 클리어 → 보상 카드 → 정비 창 → Stage2 (20) → … → Stage3 (25) → [보스전으로 ▶] → 보스 → 엔딩
사망 → 게임 오버 창 → 로비
```

- [ ] 처치 목표를 채우면 클리어 — 플레이어 무적 · 땅의 코인이 날아온다 · 클리어 보너스 (10 / 15 / 20) · 클리어 문구 3초
- [ ] 클리어 중 쌓인 **레벨업 카드**가 문구 뒤에 나온다 (스킵되지 않는다)
- [ ] 보상 카드 3장 중 1 (새 무기 · 레벨 업 · 부착물 · 서브 능력 · 진화) — 줄 것이 없으면 그냥 넘어간다
- [ ] 정비 창 → [다음 스테이지 ▶] · Stage3 은 "보스전으로 ▶" · 보스를 잡으면 바로 엔딩 (보스 스테이지엔 보상 · 정비가 없다)

### 9-2. 재화 · 정비 창

- [ ] 몬스터를 잡으면 **코인이 바닥에 떨어지고**, 3.5m 안에 들어가면 날아와 지갑으로 · 오른쪽 위 크레딧
  - 몬스터 쪽 코드에 처치 신호 줄이 들어가 있다 (예전 문서의 "코인이 안 떨어진다"는 지난 이야기) — 떨어지는지 · 개수가 몬스터마다 다른지 (A 1 · B 2 · C 3 · D 2)
- [ ] 지갑은 스테이지를 넘어 유지 · 죽은 뒤에는 늘지 않는다
- [ ] 정비 창 — 무기 줄 (새 무기 2 + 강화 1, 진화 카드가 있으면 맨 앞) · 장비 줄 (사수 부착물 3 / 검사 서브 능력) · 오른쪽 "내 장비" 판
- [ ] 돈이 모자란 카드는 가격이 붉다 · 사면 지갑이 줄고 "구매함" 덮개 · 그 밖에 못 사는 이유(칸 가득 등)는 카드에 글로
- [ ] [새로고침] 비용이 할 때마다 오른다 (3 + 스테이지 − 1 + 2 × 횟수)
- [ ] 정비 동안 시간이 멈추고 시간 제한이 없다 · 장비 HUD · 조합식 판이 숨는다
- [ ] 수입 감각 — 한 번 들러 1 ~ 2개 사는 정도인가 (Stage1 ≈ 40 · Stage2 ≈ 55 · Stage3 ≈ 70)

### 9-3. 이벤트 겹침 (예전 버그 — 고쳐짐)

- [ ] 클리어 직전에 레벨업이 겹쳐도 **레벨업 카드가 사라지지 않는다**
- [ ] 클리어 순간 · 보상 창에서 죽는 일이 없다 (클리어 무적)
- [ ] 죽은 채로 다음 스테이지로 넘어가지 않는다 (사망 > 클리어 > 레벨업)
- [ ] 보스와 동시에 쓰러지면 먼저 일어난 쪽

## 14. 알려진 이슈 · 아직 안 한 것 (버그 아님)

| 항목 | 내용 |
|---|---|
| 넓은 화면 | 16:9 보다 넓으면 상단 HUD(팀원 `PlayerStateUI`)가 잘린다 |
| 총알 | 지형(벽)을 관통한다 — 벽 충돌 없음 |
| 무기 위 부착물 모델 | 아직 없다 — 보이는 신호는 조준선 · 탄 색 · 유탄 · 총검 날 · 폭발 · 고리 |
| 서브 능력 변형 전용 모션 | 추격 도착 베기 · 방패 던지기 팔 동작은 기존 모션(와이어 · 밀치기)을 쓴다 |
| 상위 무기 남은 것 | 서브 능력 변형 연동 (예: 작살이면 사슬검이 5명 끌기) · 일시정지 조합표 · 폭격 편대 떨어지는 폭탄 연출 (지금은 폭발탄) · 팔랑크스 왼팔 방패 모델 |
| 정비 창 부착물 | 32종을 3칸 무작위로 팔아 원하는 것을 만나기 어렵다 (부위별 칸 · 잠금은 제안 단계) |
| 테스트 룸 | 적 AI 가 없다 · 일반 부착물(조준경 · 총구 · 탄창 …) · 서브 능력 변형(반사판 외)을 줄 곳이 없다 → 실제 판 정비 창 |
| 팀원 자동 스킬 | 파이어볼 · 표창 · 토네이도 · 전격 샷은 레벨업 카드로 얻는다 — 테스트 룸에는 없고 연습 규칙도 적용되지 않는다 |
| 소리 없음 | 보상 카드 선택음 · 몬스터 개별 공격 · 피격 · 사망음 · 보스 공격음 · 로비 버튼 |
| 효과음 슬라이더 밖 | 업그레이드 카드 성공 · 실패, 몬스터 B 돌진 예고음, 충전 레이저 충전음 (전체 음량으로만) |
| 옛 발사 체계 | `Gun` 컴포넌트가 플레이어 프리팹에 켜진 채 남아 있다 (발사에는 관여 안 함) |
