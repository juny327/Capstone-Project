# 플레이어 파트 핵심 정리

> 2026-10-28 기준 · 수치는 프로젝트 데이터(에셋 · 프리팹)에서 직접 확인한 값
> 자세한 목록은 같은 폴더의 [총기 부착물 종류](총기부착물-종류.md) · [사운드 효과](사운드-효과.md) · [최종 상위 무기](최종-상위무기.md)

**한 줄 요약** — 사수 · 검사 두 캐릭터가 무기 9종(+ 드론)으로 싸우고, 스테이지 사이 정비 창에서 부착물 · 서브 능력을 사서 키우며, 무기 Lv3 + 짝 장비로 상위 무기 12종으로 진화한다. 로비에서 무기를 고르면 캐릭터 · 3D 모델 · 조합식이 바로 보인다.

---

## 1. 캐릭터 2종

| 항목 | 사수 | 검사 |
|---|---|---|
| 체력 · 받는 피해 | 100 · 100% | 140 · 85% |
| 이동 속도 | 기본 | +10% |
| 스태미나 | 100 | 120 |
| 회피 (우클릭) | 구르기 — 0.75초 · 4m(달리면 5m) · 무적 | 패링 — 막고 밀치고 탄을 되돌린다 |
| 무기 | 총 6종 | 근접 3종 |
| 키우는 것 | 총기 부착물 6부위 · 하부 E 능력 | 서브 능력 2칸 (E · F) · 레벨업 변형 |

- 플레이어 프리팹은 하나, 캐릭터 데이터(`Scripts/Data/Characters/CH_*`)만 다르다
- 사수 · 검사 몸 색은 아직 같다 (`bodyMaterial` 비어 있음)

## 2. 조작

| 키 | 동작 |
|---|---|
| WASD · Space | 이동 · 점프 |
| Shift | 달리기 ×1.6 — 스태미나 초당 25 소모, 달리지 않으면 회복 (걸을 때 초당 8 · 멈추면 18) |
| 마우스 | 조준 — 공격은 사거리 안의 적에게 **자동** |
| 우클릭 | 회피 (사수 구르기 · 검사 패링) — 구르기는 다시 쓰기까지 4초 |
| Q · 휠 / R | 무기 교체 (손 4칸) / 장전 |
| E · F | 사수: 하부 부착물 능력(E) / 검사: 서브 능력 1 · 2 |
| Z | 장비 HUD 상세 (효과 한 줄) |
| ESC | 설정창 (음량 · 일시 정지) |

키는 `Resources/Settings/KeyBindings` 에서 바꾼다.

## 3. 패링 (검사)

| 항목 | 값 |
|---|---|
| 판정 | 누른 뒤 0.2초 — 주변 2m + 커서 쪽 5m · 70° |
| 적 | 3m 밀쳐 내고 경직 |
| 탄 | 칼면 각도로 거울 반사 · 속도 ×1.4 · 피해 ×1.5 |
| 성공 보상 · 쿨타임 | 0.6초 무적 · 5초 (성공 · 헛침 같음) |

## 4. 무기 9종 + 드론

| 구분 | 무기 | 피해 · 간격 | 특징 |
|---|---|---|---|
| 총 (사수) | 소총 | 2 · 0.3초 · 탄창 30 | 균형 잡힌 기본 무기 |
| | 기관단총 | 1.33 · 0.12초 · 45 | 빠른 연사 · 넓은 퍼짐 |
| | 스나이퍼 | 12 · 1.6초 · 5 | 적 3명 관통 |
| | 샷건 | 1.4 × 8발 · 0.9초 · 6 | 가까이서 강함 |
| | 전격 소총 | 3.2 · 0.5초 · 사거리 14m | 맞은 적 주위로 전기가 퍼짐 |
| | 충전 레이저 | 18 · 2.2초 · 사거리 18m | 모았다가 일직선 관통 |
| 근접 (검사) | 검 | 6 · 0.7초 · 3m · 120° | 부채꼴 베기 |
| | 대검 | 16 · 1.4초 · 4m · 160° | 느리지만 넓은 양손 베기 (양손 IK) |
| | 창 | 9 · 0.9초 · 5m · 40° | 멀리 찌르기 |
| 서브유닛 | 드론 | 2 · 0.8초 | 손 무기와 따로 항상 동작 (2칸) |

- 손 무기 4칸 + 서브유닛 2칸, **모든 무기 최대 Lv3**
- 원본(`WeaponData`)은 실행 중 바꾸지 않고, 레벨 · 카드 · 부착물 효과는 누적값(`WeaponModifier`)에 쌓아 `Compose()` 로 합성한다

## 5. 한 판의 흐름 · 정비 창

```
로비(무기 선택) → Stage 1 → 2 → 3 → 보스 → 엔딩
         각 스테이지: 처치 목표 15 · 20 · 25 → 클리어 → 레벨업 카드 → 보상 카드(3장 중 1) → 정비 창
```

| 정비 창 | 내용 |
|---|---|
| 무기 줄 | 새 무기 2 + 강화 1 + 진화 1 (진화는 무료 · 맨 앞) |
| 장비 줄 | 사수: 부착물 3 / 검사: 서브 능력 3 |
| 크레딧 | 몬스터 코인 + 클리어 보너스 10 · 15 · 20 |
| 가격 | 스테이지마다 +10% |
| 새로고침 | 3부터 · 스테이지마다 +1 · 쓸 때마다 +2 |

- 부착물을 사면 **달 총을 고른다** (달 수 있는 총만 밝아지고, 마우스를 올리면 바뀔 수치를 먼저 보여 준다)
- 정비하는 동안은 시간이 멈춘다 · 레벨업 · 클리어 · 사망이 겹치면 '사망 > 클리어 > 레벨업' 순으로 처리
- 값은 `Resources/Economy/EconomySettings` · `Resources/Shop/ShopCatalog`

## 6. 커스터마이징

- **사수 — 총기 부착물 32종** (조준경 3 · 총구 5 · 하부 4 · 탄창 2 · 탄 6 · 개조 12) → [총기 부착물 종류](총기부착물-종류.md)
  - 등급: 기본 5(대가 없음) · 균형 14(대가 있음) · 개조 13(공격 방식 변경, 무기 Lv3 부터)
- **검사 — 서브 능력 2칸**

| 항목 | E · 그랩 훅 | F · 에너지 방패 |
|---|---|---|
| 동작 | 와이어로 처음 닿은 적을 끌어와 경직 (보스면 내가 끌려감) | 누르는 동안 정면 120° 막기 · 떼면 밀치기 |
| 수치 | 8m · 경직 1초 · 쿨타임 7초 (빗나가면 2초) | 내구도 50 · 깨지면 4초 · 들면 이동 ×0.6 |
| Lv2 변형 | A 작살 (30° 안 2명 더) / B 충격 와이어 (경직 +1초 · 피해 ×2) | A 반사판 (정면 탄 되돌림) / B 강화 방벽 (내구도 90 · 회복 ×1.5) |
| Lv3 변형 | A 넘기기 (내 뒤 3m) / B 추격 (내가 날아가 베기 ×1.5) | A 방패 돌진 (5m · 무적) / B 방패 던지기 |

- 정비 창 새 능력 25 크레딧 · 레벨업은 변형 A / B 를 나란히 진열
- **작은 조합 7종** — 재료를 같이 갖추면 저절로 켜진다
  - 네이팜 유탄 · EMP 유탄 · 화염 고리 · 테슬라 노바 · 폭파 돌격 (사수) / 거울 패링 · 방패 받기 (검사)

## 7. 상위 무기 12종

- 조건: **무기 Lv3 + 짝 장비를 가지고만 있으면** → 보상 카드(반드시 1장) · 정비 창 무기 줄 맨 앞(무료)에서 진화, 거절 가능
- 짝 장비: 사수 무기 전용 개조 6 · 검사 서브 능력 1 · 팀원 레벨업 스킬 5
- 사수 8 — 처형자 · 스웜 카빈 · 회전 기관포 · 공성포 · 뇌운 · 프리즘 노바 · 태양창 · 돌풍 저격총 (10-31)
- 검사 4 — 혈검 · 거울칼날 · 중력 대검 · 아킬레우스의 창 (10-31)
- 12종 수치 → [최종 상위 무기](최종-상위무기.md)
