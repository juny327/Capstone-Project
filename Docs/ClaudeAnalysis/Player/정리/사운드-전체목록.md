## 1. 소리가 나가는 길 (믹서 · 음량)

```
                         ┌─ 설정창 "효과음" ─ SoundManager.SetSfxVolume
SoundManager (씬마다 하나) ┤
  · 효과음 칸 12개 돌려 씀  └─ 설정창 "배경음" ─ SoundManager.SetMusicVolume
  · 곡 바뀔 때 1.2초 크로스페이드
                                   설정창 "전체" ─ AudioListener.volume (게임 안 모든 소리)
```

> **설정 · 일시정지 창 점검 (2026-11-02, 배치 자동 시험 41항목 통과)** — 로비 · 테스트 룸 · Stage1 에서 슬라이더 셋에 실제 클릭이 닿고(가리는 UI 없음), 전체 → AudioListener · 배경음 → 지금 곡 음량 × 값 · 효과음 → 새로 내는 소리 음량 × 값, 0% 면 무음 · 기본값 버튼 100%. **고친 것**: 씬이 바뀐 직후 1.2초 페이드 중에 배경음을 바꾸면 페이드가 끝나며 예전 값으로 돌아가던 문제 (`SoundManager.FadeMusic` 목표를 매 프레임 다시 읽음). 게임 중에는 제목이 「일시정지」 · 왼쪽 아래 「로비로」 (테스트 룸은 바로, 스테이지는 한 번 더 눌러 확인)
