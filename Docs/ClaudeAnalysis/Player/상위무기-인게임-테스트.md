### 0-2. 자동 테스트가 이미 확인한 것 (다시 안 봐도 된다)

- 조건: Lv3 이 안 되거나 짝 장비가 없으면 진화 안 됨 → 갖추면 됨
- 보상 카드에 진화 카드가 매번 들어온다 (6/6) · 정비 창 무기 줄 맨 앞 · 무료
- 진화하면 같은 칸 · Lv3 · 부착물 · E 능력(쿨타임) 그대로, 개조 칸 잠김, 원래 무기를 다시 팔지 않음
- 처형자 연쇄 3단 · 프리즘 노바 한 발 주기(빛 튕김 · 수렴 · 2초 빔 · 탄 1발 · 커서 따라가기) · 검기 피해 · 중력장 끌기 · 붕괴 피해 — 수치가 맞게 들어간다
- **나머지 16종 (2026-10-11)** — 동작이 일어나고 수치대로 맞는다
  - 총: 유도탄이 여러 적으로 갈라짐 · 기관포 연사 ×3 까지 오르고 장전 없음 · 다총열이 돎 · 파편이 옆 적에게 · 포탄 관통 폭발 + 사거리 끝 큰 폭발 · 화염 틱 · 화상 · 불 옮김 · 레일 빔이 20m 까지 관통 + 폭발 줄 · 표식 → 5발째 일제 저격 · 전격 8명 연쇄 + 낙뢰 · 장전 중 먹구름 낙뢰(초당 약 4번) · 태양창 예고선이 모으는 동안 늘고(절반쯤 약 20m) 다 모으면 32m 기둥 · 화상 · 탄 1발
  - 근접: 사슬 6m 부채꼴 · 세 번째마다 먼 적 끌기 · 360° 충격파 + 막은 피해 더하기 · 빛의 창 13.5m 관통 + 가장 먼 적 끌기 · 방패 든 채 ×2.5 찌르기 + 떼면 돌격 ×3
  - 드론: 폭격 편대 폭발탄 · 위성 방벽이 적 탄을 막고 붙은 적을 들이받음
- **작은 조합 7종 · 조합 안내 HUD (2026-10-11)** — 조합이 켜지는 조건 · 효과 수치 · 알림 · 장비 HUD 표시 · 조합식 판 내용(무기마다 짝 · 상위 무기 · 가짐 · 진화 가능) · 테스트 룸 연습 규칙(스태미나 · 쿨타임 1초)
- 기존 부착물 · 사수 E · 검사 서브 능력 변형 · 테스트 룸 검증 — 그대로 통과

> 그래서 아래는 **"잘 보이나 · 재미있나 · 너무 세거나 약하지 않나 · 어색하지 않나"** 를 본다.

### 0-3. 적는 법

- 각 항목 앞 `[ ]` 를 `[x]` 로 바꾸고, 이상하면 옆에 한 줄 메모 (예: "검기가 너무 작아 안 보임")
- 이상한 점은 **6장 "고칠 곳"** 표에서 어느 에셋을 바꾸면 되는지 찾는다 — 대부분 코드 수정 없이 숫자만 바꾼다
- 메모를 주면 그대로 고친다

## 1. 모습 — 진화하면 "확실히 다른 무기" 같은가 (테스트 룸)

### 1-1. 진화 순간

금색 구역을 밟는다 (아무 조합이나).

- [ ] 화면이 한 번 하얗게 번쩍인다 — 눈이 아프거나 너무 길지 않은가
- [ ] 화면 위 배너 "상위 무기 / 이름" 이 읽히고 1.6초 쯤 머물다 사라진다 — 너무 길거나 짧지 않은가
- [ ] 플레이어 둘레로 고리 두 겹이 퍼진다 (테마 색 · 흰색)
- [ ] 소리가 난다 · 크기가 적당하다
- [ ] 연출이 조작을 막지 않는다 (움직이고 쏠 수 있다)

### 1-2. 무기 모델

| 상위 무기 | 볼 것 | 확인 |
|---|---|---|
| 처형자 | 소총 주황 부분이 **진홍으로 빛난다** · 조금 커졌다 | [ ] |
| 프리즘 노바 | 무지개로 색이 돌며 빛난다 · **총구 둘레에 결정 3개**가 돈다 | [ ] |
| 거울칼날 | **에너지 검신(파랑 · 가드 있는 칼)** 으로 바뀌었다 | [ ] |
| 중력 대검 | 보라 에너지 검신 · 대검답게 두껍다 | [ ] |
| 스웜 카빈 | 주황 발광 · **총열 아래 미사일 포드** | [ ] |
| 회전 기관포 | 노랑 발광 · **총구 앞 다총열 6개** — 쏠수록 빨리 돈다 | [ ] |
| 파편 폭풍 | 흰 주황 발광 (모양은 기관단총 그대로) | [ ] |
| 공성포 | 금색 발광 · **큰 포구** · 포탄이 크다 | [ ] |
| 용의 포효 | 주황 빨강 발광 · **총열 아래 연료통 · 노즐 고리** | [ ] |
| 궤도 레일캐논 | 흰 파랑 발광 · **위아래 레일 두 줄** | [ ] |
| 다중 표적 | 빨강 발광 · **위에 큰 조준경** | [ ] |
| 폭풍 코일 · 뇌운 | 흰 파랑 / 남색 발광 · **총열 코일 고리 3개** | [ ] |
| 태양창 | 흰 금색 발광 · **총구 앞 집광 고리**가 돈다 | [ ] |
| 사슬검 | **초록 에너지 검** (검 B) | [ ] |
| 성채 대검 | **노랑 에너지 대검** (검 B, 두껍게) | [ ] |
| 천공창 | **파랑 지팡이** (끝에 결정) — 창처럼 자루 뒤쪽을 쥔다 | [ ] |
| 팔랑크스 | **빨강 할버드** | [ ] |
| 폭격 편대 | 드론마다 주황 고리 · 아래 폭탄통 · 드론 수가 늘었다 | [ ] |
| 위성 방벽 | 드론마다 청록 고리 · **반투명 방패 구** · 몸 가까이(1.6m) 빠르게 돈다 | [ ] |

- [ ] **손에 쥔 모양** — 검 · 대검을 손잡이로 쥐고 있다 (칼날을 쥐거나 손에서 떠 있지 않다)
- [ ] 대검을 **두 손**으로 쥘 때 왼손이 손잡이에 붙는다
- [ ] 천공창(지팡이) · 팔랑크스(할버드)를 두 손으로 쥘 때 머리(결정 · 날)가 앞을 본다 — 거꾸로 쥐지 않았다
- [ ] 내려찍을 때 칼끝이 **바닥 아래로 깊이 들어가지 않는다**
- [ ] 패링(검사의 회피 키) 자세에서 검이 어색하게 꺾이지 않는다
- [ ] 무기를 바꿔 들었다(Q) 다시 들어도 모습이 그대로다
- [ ] 발광이 너무 밝아 하얗게 뭉개지거나, 너무 어두워 안 보이지 않는다

### 1-3. 상위 무기를 든 동안

- [ ] **발밑 고리**(테마 색, 숨 쉬듯)가 보인다 — 너무 진해서 거슬리지 않는다
- [ ] 다른 무기로 바꾸면 고리가 사라지고, 다시 들면 나타난다
- [ ] 근접 상위 무기는 휘두를 때만 **칼끝 궤적**이 남는다 (걸을 때는 안 남는다)
- [ ] 처형자 탄이 진홍색이다 (다른 총 상위 무기도 탄이 테마 색)

### 1-4. HUD · 아이콘

- [ ] 왼쪽 아래 무기 칸 글자가 **★** (진화 전 조건을 채우면 **"진화!"**)
- [ ] 오른쪽 아래 장비 판 머리글 "처형자 ★" / 진화 가능하면 "· 진화 가능" (한 줄 — 어느 상위 무기인지는 1-5 조합식 판)
- [ ] 무기 아이콘이 상위 무기 모습으로 바뀌었다 (처형자 아이콘이 분홍으로 날아가 보이지는 않는가)
- [ ] 테스트 룸 왼쪽 위 패널에 "★ 상위 무기"

### 1-5. 조합 안내 HUD (2026-10-11 — 주무기를 얻으면 조합식)

- [ ] 판 시작 · 새 주무기를 얻을 때 **왼쪽 가운데**에 조합식 판이 6초 뜬다 — "[짝 그림] 짝 이름 · 어디서 얻는지 → [상위 무기 그림] 이름"
- [ ] 검: 에너지 방패 → 거울칼날 · 그랩 훅 → 사슬검 / 소총: 지정사수 → 처형자 · 3점사 → 스웜 카빈 … 무기마다 맞다
- [ ] 짝을 가지면 "가짐"(초록), 최대 레벨까지 채우면 "진화 가능 — 처형자 (보상 카드 · 정비 창)"
- [ ] 캐릭터가 못 가지는 짝은 안 나온다 (검사가 드론을 얻으면 위성 방벽만, 사수의 드론은 폭격 편대 · 위성 방벽 중 폭격 편대만)
- [ ] 무기를 바꿔 들어도(Q) 다시 뜨지 않는다 · 다음 스테이지로 가도 다시 뜨지 않는다
- [ ] **Z (상세)** 를 켜 두면 지금 든 무기의 조합식이 계속 보인다 · 끄면 사라진다
- [ ] 조합식 판이 전투(왼쪽 적)를 가리거나 다른 HUD 와 겹치지 않는가 · 6초가 길거나 짧지 않은가
- [ ] 보상 카드로 무기를 얻으면 카드가 닫히고 시간이 흐를 때 뜬다 (카드 위에 겹치지 않는다)

## 2. 공격 이펙트 · 손맛 — 무기별 (테스트 룸)

> 무리 표적: 아래쪽 빨간 구역. 체력은 **손에 든 무기 공격력 × 0.9** — 무기를 바꿨으면 무리를 다시 세운다 (같은 구역을 두 번 밟으면 치웠다 다시 세운다).

### 2-1. 처형자 (소총 + 지정사수)

"모여 있기" → 무리 자리 쪽으로 가서 쏜다.

- [ ] 처치한 자리에 **진홍 고리가 안으로 줄어든 뒤 터진다** — "여기 터진다"가 읽힌다
- [ ] 폭발이 이웃으로 **도미노처럼 번진다** (0.08초씩 늦게) — 연쇄가 눈에 보이는가
- [ ] 폭발 크기 (반경 2m) 가 화면에서 적당하다
- [ ] 연쇄가 많이 겹칠 때 소리가 시끄럽지 않다 · 화면 흔들림이 과하지 않다
- [ ] 손맛: 진화 전 소총보다 **확실히 시원한가**

### 2-2. 프리즘 노바 (충전 레이저 + 분광 프리즘) — 2026-10-10 새 방식

"모여 있기" 앞(5 ~ 6m)에서 쏜다. 한 발 = **① 분산 1초 → ② 수렴 0.3초 → ③ 방사 2초**.

- [ ] ① 무기 둘레의 결정 3개가 **빨강 · 초록 · 파랑 빛**이 되어 꼬리를 끌며 날아가 **앞쪽 적 사이를 튕긴다** — 빛이 보이는가 · 너무 작거나 하얗게 날아가지 않는가
- [ ] ① 뒤쪽 적은 노리지 않는다 (앞 140°)
- [ ] ② 빛이 총구로 **빨려 들어오며 흰 섬광** — "이제 온다"는 신호로 읽히는가
- [ ] ③ 세 색이 감긴 **굵은 빔이 2초** — 커서를 돌리면 천천히 따라온다 (초당 120°) · 휘둘러 무리를 쓸어 담는 맛이 있는가
- [ ] ③ 빔에 맞은 자리에 색 고리가 터진다
- [ ] 한 주기(약 3.3초) 동안 다음 발이 안 나가고, 끝나면 충전(2.2초)부터 다시 — 리듬이 답답하지 않은가
- [ ] 탄창 3발 = 세 주기 → 장전. 장전이 너무 자주 / 드물지 않은가
- [ ] 빔 · 빛이 너무 화려해서 **적 탄 · 적이 안 보이는 순간**이 없는가 (실제 스테이지에서도 확인)
- [ ] 진화 전 충전 레이저보다 **"모았다 터뜨린다"** 가 확실히 느껴지는가

### 2-3. 거울칼날 (검 + 에너지 방패)

"모여 있기" 앞에서 휘두른다. 탄 되돌리기는 **실제 스테이지의 원거리 몬스터(C)** 로 본다.

- [ ] **네 번째 휘두르기마다** 초승달 검기 3개가 부채꼴로 날아간다 — "4번째" 리듬이 느껴지는가
- [ ] 검기 크기 · 밝기가 보기 좋다 (너무 작거나 흐리지 않은가)
- [ ] 검기가 사거리 8m 까지 날아가 멀리 있는 적을 맞힌다
- [ ] (스테이지) 휘두를 때 정면의 몬스터 탄이 **되돌아간다** · 되돌아간 탄이 청록으로 보인다
- [ ] 되돌리기 범위(정면 150° · 사거리 + 1.2m)가 너무 넓거나 좁지 않은가

### 2-4. 중력 대검 (대검 + 그랩 훅)

"모여 있기" 또는 "둘러싸기" 앞에서 휘두른다.

- [ ] **내려찍기**(세로베기) 때 앞 3m 바닥에 **보라 소용돌이** — 가로베기 때는 안 생긴다
- [ ] 반경 6m 안의 적이 **중심으로 끌려온다** · 끌려가는 선이 보인다
- [ ] 1.2초 뒤 **붕괴 폭발** (반경 3m) — 안으로 줄었다 바깥으로 터지는 느낌
- [ ] 중력장이 나오는 빈도 (내려찍기 50%) 가 적당한가 — 너무 드물거나 잦지 않은가
- [ ] 화면 흔들림이 과하지 않다

### 2-5. 스웜 카빈 (소총 + 3점사)

- [ ] 점사 세 발이 **서로 다른 적**을 쫓아 휘어 날아간다 — 곡선이 보이는가
- [ ] 맞은 자리에 작은 주황 폭발 (반경 1.2m) — 무리에 고르게 퍼지는 느낌
- [ ] 유도탄이 적 둘레를 맴돌기만 하고 안 맞는 일이 없는가 (2026-10-11 고침 — 가까울수록 세게 꺾는다)

### 2-6. 회전 기관포 (기관단총 + 이중 탄창)

- [ ] 쏘기 시작하면 **2초에 걸쳐 연사가 3배**까지 오른다 · 다총열 회전이 따라 빨라진다
- [ ] **장전이 없다** (탄 표시 0 · 계속 쏜다)
- [ ] 멈추면 1초에 걸쳐 느려진다 — 다시 쏠 때 처음부터 오르는 게 답답하지 않은가
- [ ] 최고 연사에서 소리 · 탄이 너무 많아 거슬리지 않은가

### 2-7. 파편 폭풍 (기관단총 + 난사)

- [ ] 맞은 자리에서 **짧은 불꽃 선 2줄**이 옆 적(4m 안)에게 튄다
- [ ] 무리 앞에서 그물처럼 번지는가 · 너무 어지럽지 않은가

### 2-8. 공성포 (샷건 + 슬러그)

- [ ] 쏠 때 **총구 충격파 고리** · 흔들림
- [ ] 큰 포탄이 **한 줄을 관통**하며 맞은 적마다 터진다 (반경 1.5m · 2m 밀치기)
- [ ] 사거리 끝(약 15m)에서 **큰 폭발** (반경 3m) — 아무것도 못 맞혀도 터진다
- [ ] 흔들림이 과하지 않은가 (연사 0.9초)

### 2-9. 용의 포효 (샷건 + 용의 숨결)

- [ ] 산탄 대신 **화염 방사** — 정면 6m · 50° 에 불길이 보인다 (2026-10-11 반투명 입자로 바꿔 밝은 바닥에서도 보이게 함)
- [ ] 맞은 적이 **불탄다** (화상 3초)
- [ ] 불타다 죽은 적 둘레(2m)로 **불이 옮겨붙는다** — 옮겨 가는 불꽃 선 · 고리
- [ ] 탄창 40 (4초 방사) → 장전 — 리듬이 괜찮은가 · 불 소리가 시끄럽지 않은가

### 2-10. 궤도 레일캐논 (스나이퍼 + 레일건)

- [ ] 탄 대신 **화면 끝까지 닿는 굵은 흰 파랑 빔** (32m · 관통 무제한)
- [ ] 0.4초 뒤 빔 자리를 따라 **폭발 고리가 앞에서부터 차례로** — 두 번 지우는 느낌
- [ ] 빔이 너무 짧게 보이거나(0.3초) 너무 가늘지 않은가

### 2-11. 다중 표적 (스나이퍼 + 반자동)

- [ ] 맞은 적 발밑에 **붉은 조준 고리** (3초) — 도는 고리가 보이는가
- [ ] **다섯 번째 발**마다 표식 있는 적 최대 6명에게 **동시에 붉은 섬광 줄** — 치명타 숫자
- [ ] 표식이 쌓이기 전에 다섯 발이 지나가 허탕 치는 일이 잦지 않은가

### 2-12. 폭풍 코일 (전격 소총 + 과부하 코일)

- [ ] 전격이 **8명**까지 이어진다 (연쇄 거리 6.75m)
- [ ] 이어질 때마다 가끔(20%) **하늘에서 낙뢰** (반경 1.5m) · 섬광
- [ ] 화면을 덮는 번개 그물이 너무 어지럽지 않은가

### 2-13. 뇌운 (전격 소총 + 방전)

- [ ] 장전(R 또는 탄이 떨어짐)하는 동안 **머리 위 먹구름**
- [ ] 구름에서 주변 8m 적에게 **낙뢰가 초당 4번** (경직 0.3초) — 장전 시간이 오히려 공격 시간
- [ ] 장전이 끝나면 구름 · 낙뢰가 멈춘다 · 장전 시작 순간의 방전(개조)도 그대로

### 2-14. 태양창 (충전 레이저 + 과충전) — 사용자 요청 반영

- [ ] 충전이 차면 **0.8초 더 모은다** (충전 지연) — 총구에 빛 고리가 안으로 모인다
- [ ] 모으는 동안 **바닥 예고선이 앞으로 뻗어 간다 (10m → 32m)** · 끝점에 작은 고리 — "모을수록 멀리"가 읽히는가
- [ ] 모으는 동안 커서를 돌리면 예고선이 따라 돈다
- [ ] 다 모으면 **굵은 흰 금빛 기둥 한 방** — 기둥 위 적 전부 · 화상 · **바닥 그을음**이 잠깐 남는다 · 큰 흔들림
- [ ] 한 발 주기(충전 약 2.3초 + 모으기 0.8초)가 답답하지 않은가 — 지연이 너무 길면 `windUpTime` 을 줄인다
- [ ] (선택) 적이 붙었을 때 모은 만큼만 일찍 쏘는 기능 — 지금은 꺼 둠 (`earlyReleaseRange` 0). 켜 보고 싶으면 6장
- [ ] 프리즘 노바(쭉 쏘는 빔)와 확실히 다른 맛인가

### 2-15. 사슬검 (검 + 그랩 훅)

- [ ] 휘두르기가 **초록 사슬 호** — 6m · 150° 로 넓어졌다
- [ ] **세 번째 휘두르기마다** 맞은 적 중 먼 3명이 앞으로 **끌려온다** (사슬 선)
- [ ] 끌어온 적을 다음 휘두르기로 다시 베는 흐름이 자연스러운가
- [ ] 칼 모델(2.3m)보다 판정(6m)이 훨씬 넓은데 어색하지 않은가 — 사슬 호가 그 차이를 메우는가

### 2-16. 성채 대검 (대검 + 에너지 방패)

- [ ] **내려찍기**마다 **360° 충격파** (반경 5m) — 바닥 균열 고리 · 밀치기 · 경직 · 큰 흔들림
- [ ] 방패 키(E · F 중 방패 칸)로 막으면 **발밑에 노란 고리**가 밝아진다 (모은 피해) → 다음 내려찍기에 더해진다
- [ ] 둘러싸였을 때 한 번에 정리되는 맛이 있는가 · 내려찍기 빈도(50%)

### 2-17. 천공창 (창 + 그랩 훅)

- [ ] 찌르기 끝에서 **빛의 창이 10m 더** 뻗는다 (청록 · 관통)
- [ ] 빛의 창에 맞은 가장 먼 적이 **내 앞까지 끌려온다** (와이어 선)
- [ ] 멀리 있는 적을 계속 끌어와 앞에 쌓이는 것이 너무 강하거나 불편하지 않은가

### 2-18. 팔랑크스 (창 + 에너지 방패)

- [ ] 방패 키(E · F 중 방패 칸)를 든 채로 **계속 찌른다** — 2.5배 빠르게 · 붉은 잔상 여러 줄
- [ ] 방패를 떼면 **6m 돌격 찌르기** (지나간 적 공격력 × 3)
- [ ] 빨라진 찌르기 모션이 끊겨 보이지 않는가 (모션은 그대로, 판정만 빨라진다)
- [ ] 방패 내구도가 금방 닳아 오래 못 드는가

### 2-19. 폭격 편대 (드론 + 가진 총의 유탄 발사기)

- [ ] 드론이 2기 늘었다 (Lv3 에서 5기) · 주황 고리 · 폭탄통
- [ ] 드론 탄이 맞은 자리에서 **폭발** (반경 1.5m)
- [ ] 조건 — 드론 Lv3 + **가진 총 중 하나에 유탄 발사기**. 장비 판 Z 상세에 "총에 유탄 발사기" 로 보인다

### 2-20. 위성 방벽 (드론 + 에너지 방패)

- [ ] 드론이 몸 가까이(1.6m) 빠르게 돈다 · 반투명 방패 구
- [ ] (스테이지 원거리 몬스터) 드론에 닿은 **몬스터 탄이 바깥으로 튕겨 나간다** · 번쩍
- [ ] 붙은 적을 드론이 **들이받는다** (피해 · 밀치기)
- [ ] 방패 구가 화면을 가리거나 플레이어가 안 보이지 않는가

### 2-21. 작은 조합 7종 (2026-10-11 — 장비 둘이 만나면 자동)

> 테스트 룸: Play 중 `Tools / 상위 무기 시험` → 아래 "작은 조합" → [갖추기]. 실제 판: 정비 창에서 하부 · 탄 부착물 / 서브 능력을 사서 맞춘다.

## 3. 테스트 룸 · Tools 창 자체

- [ ] 금색 구역을 밟으면 진화 · 안내 문구가 화면 위에 뜬다 ("소총 → 처형자 진화")
- [ ] 사수로 거울칼날 · 중력 대검 구역을 밟으면 "(시험 — 에너지 방패 없이)" 로 진화한다
- [ ] 검사로 처형자 · 프리즘 노바 구역을 밟아도 진화한다 (총을 든 검사)
- [ ] 폭격 편대 구역 — 사수는 손에 든 총(없으면 가진 총)에 유탄 발사기를 달고 진화, 검사는 "(시험 — 총의 유탄 발사기 없이)"
- [ ] 금색 구역 20개 이름 · 아이콘 · 조합 글씨가 읽힌다 (작아졌다)
- [ ] 이미 진화한 구역을 다시 밟으면 그 상위 무기를 꺼내 든다
- [ ] 진화한 상태에서 **왼쪽 선반의 원래 무기**를 밟으면 원래 무기(Lv1)로 돌아간다
- [ ] 무리 표적이 죽으면 2초 뒤 다시 선다 · HUD 에 "무리 처치 · 누적 피해 · 최근 5초 DPS" 줄
- [ ] 훈련용 해골(무한 체력) DPS 측정이 예전처럼 된다 · "측정 초기화" · "룸 초기화" · "로비로"
- [ ] `Tools / 상위 무기 시험` 창 — 상태 표시("진화함 / 진화 가능 / Lv1/3 · 짝 없음")가 맞고 [조건] · [진화] · [들기] 가 동작한다
- [ ] 화면 아래 안내 문구가 잘리지 않는다 (네 줄 — 마지막 줄 "연습 규칙 — 스태미나 무한 · 능력 쿨타임 1초")
- [ ] **연습 규칙** — 오래 달려도 스태미나가 줄지 않는다 · 그랩 · 방패 밀치기 · 유탄 · 총검 · 충격 방출기 · 패링 · 구르기를 1초마다 다시 쓸 수 있다 · HUD 쿨타임 덮개도 1초
- [ ] 테스트 룸에서 로비로 나가 실제 판을 하면 원래 쿨타임 · 스태미나로 돌아온다
- [ ] `Tools / 상위 무기 시험` 창 아래 **"작은 조합"** — 상태(켜짐 / 꺼짐) · [갖추기] 로 켜진다. 사수에게 검사 조합은 "서브 능력 칸이 없습니다" 로 거절

## 4. 실제 판 흐름 — 보상 카드 · 정비 창 (스테이지)

> 처음부터 Lv3 + 개조를 모으기는 오래 걸리므로, Stage1 에서 `Tools / 상위 무기 시험` 의 **[조건]** 으로 조건만 채우고 시작해도 된다.

### 4-1. 보상 카드

Stage1 에서 [조건] → 처치 목표를 채워 클리어 → 레벨업 카드 → **보상 카드**.

- [ ] 보상 카드 중 한 장이 **"상위 무기 — 처형자"** · 설명 "소총 → 처형자 / …" · 그림
- [ ] 카드를 고르면 정비 창으로 넘어가고, **다음 스테이지가 시작될 때** 진화 연출이 나온다 (정비 중에는 연출이 안 나온다 — 의도)
- [ ] 다른 카드를 고르면 진화하지 않고, **다음 보상 카드 · 정비 창에 다시** 나온다

### 4-2. 정비 창

- [ ] 조건을 채운 채 정비 창에 오면 무기 줄 **맨 앞에 "진화" 카드 (백금색 · 0 코인)**
- [ ] 진화 카드 때문에 무기 줄의 다른 카드(새 무기 · 강화)가 가려져도 불편하지 않은가 (무기 줄은 3칸)
- [ ] 진화한 뒤 장비 판의 **개조 칸이 잠겨** 다른 개조를 살 수 없다 (부착물 카드가 그 총을 고를 수 없음)
- [ ] 진화한 뒤에도 다른 부위 부착물은 살 수 있다
- [ ] 진화한 무기는 "강화" 카드에 안 나온다 (최대 레벨) · 원래 무기가 "새 무기" 로 안 나온다

### 4-3. 검사

- [ ] 검 Lv3 + 에너지 방패(새 서브 능력)를 정비 창에서 사면, 다음 보상 카드 · 정비 창에 거울칼날이 나온다
- [ ] 진화 뒤에도 E · F 서브 능력 · 패링이 그대로 된다

## 5. 밸런스 — 실제 판을 처음부터 (가장 중요)

> 최대 레벨이 5 → 3 으로 바뀌고 "Lv3 + 짝 장비만 있으면 진화" 로 정했으므로 판 전체의 느낌이 달라졌을 수 있다.

### 5-1. 진화 시점

| 볼 것 | 메모 |
|---|---|
| 주력 무기가 **Lv3** 에 닿은 때 (Stage ? 클리어 뒤) | |
| 짝 장비(개조 · 서브 능력)를 손에 넣은 때 | |
| **진화한 때** | |
| 그 뒤 상위 무기로 싸운 시간 (대략) | |

- [ ] 진화가 **너무 이르지 않은가** (Stage 1 ~ 2 에 진화하면 뒤가 심심해질 수 있다)
- [ ] 너무 늦지 않은가 (보스 직전이면 쓸 시간이 짧다)
- [ ] 개조 카드가 정비 창 3칸 무작위에 잘 안 나와 사수 진화가 막히지 않는가 (부착물 32종)

### 5-2. 최대 레벨 3 의 영향

- [ ] 무기 강화 · 레벨업 보상이 **일찍 끝나** 보상 카드 후보가 단조롭지 않은가
- [ ] 진화 전 무기가 **너무 약하게** 느껴지지 않는가 (레벨당 강화량은 그대로라 예전 Lv5 보다 약하다)
- [ ] 드론이 3기에서 멈추는 것이 괜찮은가

### 5-3. 상위 무기 화력

- [ ] 진화 직후 **"확 세졌다"** 가 느껴지는가 (목표: 같은 무기 대비 단일 ×2 · 무리 ×4)
- [ ] 너무 세서 Stage 3 · 보스가 시시하지 않은가
- [ ] **보스전 길이** — 상위 무기 있을 때 ___ 초 / 없을 때 ___ 초 (목표: 있을 때 60 ~ 90초)
- [ ] 네 상위 무기 사이 세기가 크게 차이 나지 않는가 (하나만 압도적이면 그것만 고른다)

### 5-4. 성능 · 가독성 (Stage 3 · 적이 많을 때)

- [ ] 처형자 연쇄 · 프리즘 노바 · 중력장에서 **프레임이 떨어지지 않는가**
- [ ] 이펙트가 겹쳐 **적 탄 · 적이 안 보이는** 순간이 없는가
- [ ] 화면 흔들림이 겹쳐 멀미 나지 않는가
