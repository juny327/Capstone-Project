## 2. 한 판의 흐름 (지금 구현)

```
로비 ─ 무기를 고르면 캐릭터가 정해진다 (사수: 총 6종 / 검사: 근접 3종)
 └▶ Stage1 (처치 15) ─ 전투 중: 레벨업 카드(경험치) · 코인 줍기
      └▶ 클리어 ─ 플레이어 무적 · 땅의 코인 흡수 · 보너스 10
           └▶ 클리어 문구 3초 ─▶ 밀린 레벨업 카드 ─▶ 보상 카드 3장 중 1 (무료)
                ─▶ 정비 창 (무기 줄: 새 무기 · 강화 / 장비 줄: 부착물 · 서브 능력 · 새로고침) ─▶ [다음 스테이지 ▶]
 └▶ Stage2 (처치 20) ─ 같은 흐름, 보너스 15
 └▶ Stage3 (처치 25) ─ 같은 흐름, 보너스 20, 버튼 이름이 "보스전으로 ▶"
 └▶ IntroScene (보스 등장 연출) ─▶ StageBoss ─▶ EndingScene
 사망 ─▶ 게임 오버 창 ─▶ 로비
```

- 다음 씬은 **빌드 순서 + 1** 로 고른다. 빌드 목록 순서를 바꾸면 흐름이 통째로 어긋난다
- 무기를 얻는 기회: 시작 1 + 보상 3 = 최대 4 → 손 슬롯 4칸과 딱 맞는다. 정비 창에서 더 살 수 있다
- 보스 스테이지는 클리어 흐름이 없어 보상 · 정비가 없다. 보스를 잡으면 바로 엔딩

## 3. 조작 · 이동

| 항목 | 값 |
|---|---|
| 이동 | 기본 속도 3 (슬로우 · 스턴은 배율 목록으로 쌓인다) |
| 달리기 (Shift) | ×1.6 · 스태미나 −25/초 (100 → 약 4초). 걷기 +8 · 정지 +18/초, 멈춘 뒤 0.5초 지나서 회복 |
| 스태미나 바닥 | 25% 가 찰 때까지 다시 못 달린다 (0 근처에서 떨리는 것 방지) |
| 구르기 (우클릭, 사수) | 4m · 무적 1.5초 · 재사용 **4초** (구르는 시간 1.5 + 쿨타임 2.5) · 입력 버퍼 0.15초 |
| 패링 (우클릭, 검사) | 5-2 |
| 공격 | **자동** — 사거리 안에 적이 들어오면 쏜다 / 벤다. 조준은 마우스 방향 |
| 장전 · 교체 · 점프 · 설정 | R · Q / 휠 · Space · ESC |
| **E · F** (검사) | 서브 능력 1 · 2칸 — 누르기(그랩) · 누르고 있기(방패). 사수의 E 는 하부 부착물 능력 자리(아직 없음) |
| **Z** | 장비 패널 상세(효과 한 줄) 켜기 / 끄기 — 다음 실행에도 기억 |
| 입력 | **신 Input System 전용** — `UnityEngine.Input` 을 쓰면 런타임 예외. E · F · Z 는 `Resources/Settings/KeyBindings` 에셋에서 바꾼다 (입력 파일은 그대로) |

**HUD** — 기존 HUD(`PlayerStateUI` — 체력 · 처치 수 · 경험치)는 그대로 두고, 새 요소는 `Canvas` 바로 아래에 붙였다.

| 자리 | 요소 |
|---|---|
| 왼쪽 아래 | 무기 슬롯 4칸(활성 = 노란 테두리, 아이콘 · 이름 · 레벨) · 구르기 / 패링 쿨타임 아이콘 · 스태미나 바(바닥나면 붉게) · **E · F 서브 능력 아이콘**(쿨타임 · 방패 내구도) |
| 오른쪽 아래 | 탄약 `24 / 30` + 총알 10칸 (탄창 0 이면 통째로 숨는다) · 그 위에 **장비 판** — 지금 든 총의 부착물 5칸 그림 + 이름 (검사는 서브 능력 E · F) |
| 오른쪽 위 | 크레딧 (스테이지에서만) |

## 4. 무기

### 4-1. 구조

```
WeaponData (SO 원본 — 절대 수정 금지)  +  WeaponModifier (업그레이드 누적 + 레벨 보너스)
                       └── Compose() ──▶ WeaponRuntimeStats (실제 사용값)
```

- `WeaponData` 를 직접 고치면 에셋에 영구 기록돼 플레이마다 수치가 쌓인다 → 업그레이드는 반드시 `WeaponModifier` 로
- 발사 게이트: 쿨다운 · 활성 · 장전 중 아님 · 탄 있음 → 적 감지 → **사거리 안** → 발사
- 슬롯: 손 4칸 · 서브유닛 2칸 (서브유닛은 교체와 상관없이 항상 동작). 무기 최대 레벨 5
- 탄창 0 = 무제한 (근접 · 드론) — 탄약 HUD 가 저절로 숨는다
- 장전 규칙: 1회 발사 = 탄 1 · 탄이 떨어지면 자동 장전 · 교체하면 장전 취소(탄약 유지) · 구르기 / 사망도 취소

\* 단일 대상 기준, 치명타 기대값 · 장전 시간 포함. `기대 피해 = 피해 × (1 + 치명확률 × (배율 − 1))`

- **밸런스 기준선**: 원거리 5.5 ~ 9, 근접 9 ~ 13 (근접은 맞으면서 싸우는 위험만큼 높게). 관통 · 광역이 있으면 낮은 쪽에 둔다
- **레벨당 효과** (보상 카드 "레벨 업" · 정비 "강화"): 소총 피해 +0.3 · 기관단총 +0.2 · 스나이퍼 +1.8 · 샷건 +1발 · 전격 +0.5 · 충전 +3 · 검 +0.9 · 대검 +2.4 · 창 +1.35 · 드론 +1대 — 레벨당 약 +15%. 앞의 여섯은 2026-10-04 에 채웠다 (전에는 0 이라 레벨만 오르고 성능이 그대로였다)
- 무기를 더 넣을 때 함께 손볼 곳: 로비 선택 도구 · 아이콘 렌더 도구의 무기 배열, 슬롯 4칸(`maxHeldSlots` · HUD 칸 수)

### 4-3. 스테이지 보상 — 구현

```
StageReward (추상 ScriptableObject) — Title · Description · Icon · CanOffer(player) · Apply(player)
  └ WeaponReward (구현됨)    └ AttachmentReward (부품 — 나중에)
```

- 새 보상 종류는 `StageReward` 를 상속하고 풀(`StageRewardPool`)에 넣으면 끝 — 매니저 · 창 · 카드 · `GameManager` 는 고치지 않는다
- 후보 규칙은 `CanOffer` 한 곳. 캐릭터 규칙은 `WeaponController.CanAcquire` 한 곳
  - 이미 가진 무기 → 레벨업 카드("레벨 업" 꼬리표) · 슬롯이 차면 레벨업만 · 최대 레벨이면 빠진다
- 안 멈추게: 보상 창이 없으면 건너뛴다 · 줄 것이 없으면 바로 넘어간다 · 60초 응답이 없으면 강제 진행
- "건너뛰기" 버튼은 넣지 않는다 (기회 3번 × 슬롯 4칸이 맞물려 있다)

### 4-4. 이벤트 (`GameEvents`) — 판 흐름에 쓰는 것

| 이벤트 | 보내는 곳 | 받는 곳 |
|---|---|---|
| `OnPlayerSpawned(Transform)` | `GameAppManager` | HUD · 재화 시스템 |
| `OnEnemyKilled` · `OnStageProgress` | `EnemyManager` · `StageManager` | 처치 진행 |

## 5. 캐릭터 2종 — 사수 · 검사

### 5-1. 구조

- **플레이어 프리팹은 하나**, 차이는 `CharacterData`(`CH_Gunner` · `CH_Swordsman`)가 낸다 → `CharacterLoadout` 이 적용
- 로비에 두 영역을 좌우로 놓고, **무기를 누르면 그 무기의 캐릭터가 정해진다**. 외형은 같고 무기로 구분한다
- 교차 획득은 **불가** — 검사는 총을, 사수는 근접 무기를 얻지 못한다 (보상 · 상점 후보도 저절로 걸러진다)

| | 사수 | 검사 |
|---|---|---|
| 최대 체력 | 100 | **140** |
| 받는 피해 | ×1.0 | **×0.85** |
| 이동 속도 | ×1.0 | **×1.1** |
| 최대 스태미나 | 100 | 120 |
| 회피 | 구르기 — 자리를 벗어난다 | **패링** — 자리를 지키며 밀어낸다 |
| 탄창 · 장전 | 있음 | 없음 |
| 커스터마이징 | 총기 부착물 (4-5) | **서브 능력 2칸 E · F** (5-5) |

검사 수치는 초안이다 — 실제 스테이지에서 조정이 필요하다.

### 5-2. 패링 (검사)

| 항목 | 값 |
|---|---|
| 판정 | 누른 뒤 **0.2초** 동안 매 프레임 검사 — 주변 원 2m(360°) ∪ 커서 부채꼴 5m · 70° |
| 성공 | 범위 안의 것 전부: 적 **밀쳐내기 3m + 경직 1초** · 적 투사체 **쳐내기** · 플레이어 무적 0.6초 |
| 쿨타임 | **5초 — 헛쳐도 같다** (헛침은 전용 소리 + HUD 아이콘 붉게) |
| 쳐낸 투사체 | 몬스터가 쏜 **그 투사체**가 **칼면 거울 반사**로 날아간다. 속도 ×1.4 · 피해 = 든 근접 무기 공격력 ×1.5 |
| 보스 상대 | 밀지 않음 · 보스 투사체 제외 · 무적만 |

- 칼면은 캐릭터 정면(커서 방향)에 수직으로 본다 — 비스듬히 오면 반대쪽 비스듬히, 정면이면 곧장 되돌아간다. 스치는 탄도 최소 20° 는 꺾인다
- 적 투사체(`RangedProjectile`, Enemy 폴더)는 고치지 않는다. 쳐내는 순간 그 컴포넌트를 끄고 `DeflectedProjectile` 이 비행을 넘겨받았다가, 끝나면 되돌리고 풀로 돌려보낸다
- 연출: 금속 타격음 + **직접 합성한 "팅~" 여운** · 히트 스톱(×0.05, 0.06초) · **주황 불똥**(바닥에서 튀고, 칼면을 긁고, 밀어낸 적 자리에도) · 무기별 자세(검 맞받아치기, 대검 · 창 양손 방어 IK)

### 5-3. 근접 공격

- 사거리 = 인식 범위 — **사거리 + 0.5m** 안 정면 부채꼴에 적이 있을 때만 휘두른다
- 휘두를 때마다 **기본 공격 / 양손 내려찍기** 무작위. 같은 것이 3번 이어지지 않고, 고른 모션의 부채꼴에 적이 없으면 다른 모션으로
  - 기본 공격: 검 한손 가로베기 · 대검 양손 가로베기 · 창 양손 찌르기
- 무기 길이 검 2.3 · 대검 3.5 · 창 5.0m (칼끝이 사거리 끝에 닿게) · 칼끝이 바닥 아래로 안 들어가게 보정 · 왼손은 IK 로 자루에 (`MeleeTwoHandGrip`)
- 모션: Kevin Iglesias 무료판 + **KayKit 양손 모션(CC0)** — 하체 · 골반이 고정돼 몸이 뜨지 않는다
- 모델: Futura — 검 A 주황 · 검 A 빨강(대검) · 할버드 파랑(창)
- 에셋 · 씬 구성은 `Tools / Character Setup / 전체 실행` 한 번 (`CharacterSetup.RunAllBatch`)

### 5-4. 실제 스테이지에서 아직 확인할 것

- [ ] 적 밀쳐내기 (`NavMeshAgent.Move`) — 테스트 룸에는 적 AI 가 없어 자동 검증을 못 했다
- [ ] 검사 수치 · 패링 5초의 체감

### 5-5. 서브 능력 — 그랩 훅 · 에너지 방패 (2026-10-04)

- 칸 2개 — 처음 얻은 능력은 **E**, 두 번째는 **F**. 정비 창 장비 줄에서 얻고, 다시 사면 레벨업(최대 3). 두 칸이 차면 레벨업만 나온다
- 한 번에 하나만 — 방패를 든 채 다른 능력 키 · 패링을 누르면 방패를 내리고 그쪽을 쓴다. 시간이 멈춰 있으면 입력을 받지 않는다

| | 그랩 훅 (누르기) | 에너지 방패 (누르고 있기) |
|---|---|---|
| 동작 | 왼손 와이어(8m)가 **처음 닿은 적**을 내 앞 1.5m 로 끌어오고 경직 1.2초 · 피해 = 무기 공격력 × 0.5 | 몸 앞 반투명 방패면 — **정면 120°** 피해를 막는다 (`hitDirection` 으로 판단) |
| 예외 | 자폭 적은 끌지 않고 경직만 · **보스에게는 내가 끌려간다**(대시 · 무적) | 들고 있는 동안 자동 공격 멈춤 · 이동 ×0.6 · 보스의 감속 · 기절은 못 막는다 |
| 쿨타임 · 게이지 | 맞히면 **7초**, 빗나가면 **2초** | 내구도 **50** — 0 이면 깨지고 4초 못 편다, 내리면 2초 뒤 초당 20 회복 |
| 떼면 | — | 0.3초 이상 들었으면 **밀치기** — 정면 2.5m 적을 2m 밀고 경직 0.8초 (쿨타임 3초) |
| 레벨업 | 맞혔을 때 쿨타임 −1초씩 | 내구도 +20씩 |
| 모션 | KayKit 왼주먹 뻗기 (`HookThrow`) | KayKit 방패 들기 · 밀치기 (`ShieldUp` · `ShieldBash`) |

- 적 코드는 고치지 않는다 — 경직은 공개된 `Enemy.ApplyShock`, 끌기 · 밀기는 `NavMeshAgent.Move` (패링과 같은 방식)
- 수치는 능력 프리팹 `Prefabs/SubAbility/SA_Grapple` · `SA_Shield` 인스펙터에서, 이름 · 설명 · 가격은 `Scripts/Data/SubAbilities/SA_*.asset`
- ⚠ `ApplyShock` 은 스킬 담당의 "전격" 경직이다 — 나중에 전격 이펙트를 넣으면 그랩 경직에도 번개가 보인다. 몬스터 · 스킬 담당에게 일반 경직으로 같이 쓴다고 알릴 것

## 6. 재화 · 정비(상점) — 1단계 구현

### 6-1. 흐름

- 몬스터를 잡으면 **코인이 바닥에 떨어진다** — 3.5m 안에 들어가면 날아와 지갑으로
- 클리어하면 땅에 남은 코인이 모두 날아오고 **클리어 보너스**(10 / 15 / 20)가 들어온다
- 보상 카드 뒤 **정비 창** — 카드를 클릭하면 산다. 카드는 두 줄
  - **무기 줄** — 새 무기 2 + 가진 무기 강화 1
  - **장비 줄** — 사수는 **부착물 3**, 검사는 **서브 능력**(새 능력 · 레벨업)
  - 오른쪽 **내 장비** 판 — 가진 무기마다 부착물 5칸 그림 + 이름, 검사는 서브 능력 E · F
  - 부착물을 누르면 **장착할 총을 고른다** — 달 수 있는 총만 밝아지고, 마우스를 올리면 바뀌는 수치("탄창 30 → 45")가 나온다. 우클릭 · 취소 버튼 · 같은 카드 다시 누르기 = 취소 (돈은 그대로). 달 수 있는 총이 하나뿐이고 그 부위가 비어 있으면 바로 산다
  - 진열이 적으면 있는 카드만 그 줄 가운데로
  - [새로고침] 은 크레딧을 내고 진열을 바꾼다 · [다음 스테이지 ▶] 로 출발
  - 정비 동안 시간은 멈추고, 시간 제한이 없다
- 지갑(`Wallet`)은 플레이어에 붙어 스테이지를 넘어 유지된다. 죽은 뒤에는 늘지 않는다
- 크레딧 HUD 는 스테이지 오른쪽 위

## 7. 이벤트 겹침 버그 — 1단계 수정 완료

**증상**: 여러 이벤트가 겹치면 ① 업그레이드 카드가 스킵되고 ② 죽었는데 다음 스테이지로 넘어가 HP 0 으로 못 움직인다.

**원인**

1. 판의 상태(전투 · 레벨업 · 클리어 · 보상 · 사망)를 한 곳에서 관리하지 않는다 — 각 시스템이 서로 묻지 않는다
2. `Time.timeScale` 을 7곳이 직접 덮어쓴다 — 마지막에 쓴 쪽이 이긴다
3. 플레이어는 씬을 넘어 살아남는데 `GameManager` · 카드 창은 씬마다 새로 생긴다 → 처리 중이던 레벨업이 사라진다

**규칙: 사망 > 클리어 > 레벨업.** 한 번 정한 상태는 다른 이벤트가 뒤집지 못한다.

| 고친 파일 | 바꾼 것 |
|---|---|
| `GameManager.cs` (Core) | 사망을 들으면 판 종료 → 이후 클리어 · 레벨업 · 승리 무시 · 클리어 순간 플레이어 무적 · 클리어 중 레벨업은 쌓았다가 **클리어 문구 뒤 · 보상 앞 · 보상 뒤**에 처리 · 다른 창이 떠 있으면 시간을 되돌리지 않음 · 보상 뒤 정비 단계 |
| `GameAppManager.cs` (Core) | 다음 스테이지에서 클리어 무적 해제 · 죽은 플레이어로 들어가면 오류 로그 후 로비로 (안전장치) |
| `PlayerStats.cs` (Player) | 죽은 뒤에는 경험치를 받지 않음 |

- 검증: 고치기 전 7개 실패 → 고친 뒤 21개 통과. 2026-10-02 main 무결성 재검증 17개 통과 (보상 · 정비 흐름 포함)
- 기본값: 보스와 동시 사망은 **먼저 일어난 쪽**, 클리어 때 남은 적은 그대로 두고 플레이어 무적만

**남은 단계**

| 단계 | 내용 |
|---|---|
| 2단계 | `GamePause` — 시간 정지를 한 창구로 (멈춤 요청이 하나라도 남으면 0). 설정창 · 히트 스톱 · 게임 오버까지 |
| 3단계 | 판의 상태 머신 (Playing → LevelUp / StageClear → Reward → Maintenance → NextStage, Dead · Won) |
| 선택 (각 담당) | `StageManager` 클리어 한 번만 보내기 · `EnemyManager` 사망 / 클리어 때 생성 정지 · 스킬 사망 시 정지 · 클리어 때 구슬 흡수 — 지금은 버그와 무관해졌다 |

### 10-3. SF 세계관 — 추천 "차원 균열"

> 채굴 행성 광산 최하층에 차원 균열이 열렸다. 새어 나온 에너지 **에테르**가 죽은 것을 움직여, 균열 너머에서 스러진 전사들이
> 뼈와 녹슨 무기만 남은 채 기어 나온다. 강화 전투 프레임을 입은 대응 부대가 드롭 포드로 강하해 균열 3층을 뚫고
> 핵을 지키는 **수호 골렘**을 쓰러뜨려 균열을 봉인한다.

| 게임 | 설정 | 게임 | 설정 |
|---|---|---|---|
| 사수 / 검사 | 레인저 / 브레이커 프레임 | 경험치 구슬 | 에테르 샤드 |
| 검사가 총을 못 드는 이유 | 출력이 날 방출기로 몰려 사격 통제 장치가 없다 | 레벨업 / 레벨업 카드 | 출력 상승 / 현장 튜닝 |
| 패링 | 키네틱 디플렉터 — 에너지 장 평면에 **거울처럼 반사** | 크레딧 | 정제한 에테르 |
| 구르기 | 스러스터 회피 | 보상 카드 | 궤도 보급 (무료) |
| 무기 레벨 / 3티어 | 교정 / 형태 해방(오버클럭) | 상점 | 보급선 조달 AI |
| Stage1 ~ 3 · 보스 · 엔딩 | 균열 1 ~ 3층 · 수호 골렘 · 균열 봉인 | 사망 | 프레임 파손 → 긴급 회수 |
| 테스트 룸 | 착륙선 모의 전투실 | 적 C 주황 구체 | 에테르 사수 → 에테르 = 주황 |

- 먼저 할 일: **용어 통일 · 카드 문구 · 에테르 색(주황)** — 글자 · 색 값만 바꾼다
- 고유명사(행성 · 부대 · 에너지 이름)는 게임 이름과 함께 정한다

- `Tools / 커스터마이징 / 전체 만들기`(`CustomizationSetup`)는 부착물 · 서브 능력 데이터 · 능력 프리팹 · 키 배치를 **없을 때만** 만들고, 장비 HUD · 상점 창은 매번 다시 만든다. 처음 값은 "기본값으로 되돌리기"

### 11-3. 에셋 · 라이선스

- 가져온 에셋은 **가져온 위치 그대로** 둔다 — 종류별로 재배치하면 브랜치 병합에서 충돌한다
- Unity 에셋 스토어는 **좌석당 라이선스** — 파일을 넘기지 말고 각자 자기 계정으로 받는다
- 에셋을 무단 재배포하는 비공식 사이트는 쓰지 않는다
- 기록: `Assets/AUDIO_LICENSES.md` · `Assets/MODEL_LICENSES.md`. 크레딧 의무는 배경음(Torone, CC BY 4.0)뿐
