## 1. 한눈에

지금 보스전은 **따로 도는 인트로 씬(약 9초) → 보스 스테이지에서 2초 뒤 골렘이 그냥 나타남 → 쓰러뜨리면 바로 엔딩**이다. 보스는 추적 + 근접 2종 + 스킬 3종 고정 순환이고 페이즈가 없다.

1. Stage3 처치 70 → 레벨업 카드 → "스테이지 클리어" → 보상 카드 → 정비 창
2. **인트로 씬** — 타임라인 약 9.3초 (골렘이 걸어 나와 포효 · "Boss Spawn" 문구) → "Start" 버튼을 눌러야 넘어감
3. **보스 스테이지** — 2초 뒤 보스가 켜짐 (등장 연출 없음) · 일반 몬스터는 안 나옴
4. 보스 체력 0 → 쓰러지는 동작 1.2초 → **엔딩 씬** ("You Win" → 로비로). 플레이어가 죽으면 보스는 승리 동작

| 항목 | 지금 |
|---|---|
| 보스 | 바위 골렘 (Mini Legion Rock Golem — Polyart 판) |
| 체력 | **1000** (11-12, 예전 300) — 피해를 정수로 잘라 받는다 (0.8 → 0) |
| 이동 | 3.5 (플레이어 걷기 3 보다 빠름) · 15m 안에 들어오면 쫓아옴 |
| 근접 | 5m 안 · 오른손 ↔ 왼손 번갈아 · 피해 20 |
| 스킬 | 바위 던지기 (30) → 둔화 장판 → 기절 장판 순서 반복, 끝날 때마다 3초 쉼 (한 바퀴 약 13초) |
| 걸리는 시간 | Stage3 빌드 (소총 Lv3 + 보조 3칸) 약 **77초** — 카드 · 스킬 없이 제자리 측정 (`Logs/evo_resume/kept_HpCheck.cs`) |

## 2. 보스 등장 연출

등장 연출은 **보스 스테이지가 아니라 따로인 인트로 씬(`IntroScene`)에만** 있다. 빌드 순서가 Stage3 다음이 IntroScene 이라 정비 창을 닫으면 여기로 온다. 플레이어는 숨겨지고 배경음은 없다 (배경음 목록 `AUDIO/MusicSet` 에 IntroScene 이 없어 앞 곡이 페이드아웃).

**인트로 타임라인 (`Timeline/TimeLineIntro`, 약 9.3초)**

| 시간 | 일어나는 일 |
|---|---|
| 0 ~ 1.3초 | 골렘 GetHit 동작 — 깨어나는 느낌 |
| 1.5 ~ 4.0초 | 등장 이펙트(`BossSpawnEffect`) 두 개 · 1.6 ~ 3.9초 걸어 나옴 (Walk) |
| 3.9 ~ 6.6초 | 포효 (Victory 동작) · 4.0 ~ 6.1초 등장 이펙트 두 개 더 |
| 6.6 ~ 9.3초 | 대기 (Idle) · 문구 **"Boss Spawn"** 이 뜨는 애니메이션 |
| 끝 | **"Start"** 버튼이 나타나고, 누르면 보스 스테이지 (`SequenceController`) |

- 카메라: Cinemachine 카메라 + 녹화한 애니메이션 트랙
- 문구 · 버튼이 영어 임시 글자다 ("Boss Spawn" · "Start" — 버튼은 Space Exploration GUI Kit 보라 버튼)

**보스 스테이지 (`StageBoss`)**

1. 플레이어가 시작 자리에 서고, 보스는 꺼진 채로 있다
2. **2초 뒤 보스가 켜진다** (`BossTestSpawner` — 이름은 시험용이지만 실제로 쓰임). 등장 이펙트 · 카메라 연출 없이 그 자리에 나타남
3. 켜지는 순간 보스 등장 소리 (Kenney forceField_000) · 배경음은 Torone action-1
4. 보스 체력바는 **처음 맞을 때** 뜬다 — 빨강 · 주황 · 초록 막대 3개로 3등분 (페이즈는 없다)
5. 보스는 플레이어가 15m 안에 들어오면 움직이기 시작, 스킬은 켜진 뒤 2초부터

**끝** — 체력 0 → Die 동작 1.2초 → 동작 끝 이벤트로 승리 → 엔딩 씬 (타임라인 뒤 "You Win" 패널 · 로비 버튼). 클리어 보상 · 판 결과 화면은 없다.

## 3. 보스 패턴

보스는 두 줄이 따로 돈다 — **움직임 · 근접** (상태 기계, 0.2초마다 판단) 과 **스킬 순환** (고정 순서). 둘은 서로를 기다리지 않아 근접 중에도 스킬이 나간다.

| 패턴 | 언제 | 예고 | 피해 · 효과 | 시간 |
|---|---|---|---|---|
| 대기 | 플레이어가 15m 밖 | — | — | — |
| 추적 | 15m 안 | — | 내비메시로 쫓아옴 · 속도 3.5 | 계속 |
| 근접 1 (Attack01) | 5m 안 · 번갈아 | 동작만 (바닥 표시 없음) | 오른손 판정 **20** · 화면 흔들림 0.5 | 동작 2.67초 · 판정 1.5 ~ 2.4초 |
| 근접 2 (Attack02) | 5m 안 · 번갈아 | 동작만 | 왼손 판정 **20** | 동작 2초 · 판정 0.8 ~ 1.7초 |
| 바위 던지기 | 스킬 1번째 | 발밑 표식이 1.2초 동안 따라옴 + 화면 경고 UI | 머리에서 바위를 포물선으로 (높이 5m · 1.2초) → 반경 2m 폭발 **30** · 흔들림 1.2 | 약 2.4초 + 쉼 3초 |
| 둔화 장판 | 스킬 2번째 | 플레이어 자리 표식 1초 | 반경 5m 안 이동 ×0.5 · 3초 | 1초 + 쉼 3초 |
| 기절 장판 | 스킬 3번째 | 장판 자체 (3초 유지) | 플레이어 둘레 8m 안 무작위 3 ~ 4개 · 밟으면 **2초 이동 불가** (머리 위 이펙트) | 1초 + 쉼 3초 |
| 승리 | 플레이어가 죽음 | — | Victory 동작 · 움직임 · 공격 멈춤 | — |

- 스킬은 보스가 켜진 뒤 2초부터 바위 → 둔화 → 기절 순서를 끝없이 반복한다 (한 바퀴 약 13초)
- **없는 것**: 페이즈(체력바는 3등분인데 단계 변화 없음) · 분노 · 부하 몬스터 · 맞았을 때 반응 (GetHit 동작은 인트로에서만)
- 플레이어의 경직 · 둔화 · 끌기 효과는 일반 몬스터에만 먹힌다 — 보스는 피해만 받는다 (그랩 훅은 내가 보스에게 끌려감)
- 위험한 조합: 기절 장판(2초) 위에서 근접 20 · 바위 30 이 겹치면 한 번에 50 (사수 체력 100)

## 5. 수치 · 바꿀 곳

보스 수치는 대부분 **`StageBoss` 씬의 `Boss` 오브젝트 컴포넌트 값**이고, 몇 개는 코드에 숫자로 박혀 있다 (보스 담당 영역 — 바꿀 때 상의).

| 값 | 지금 | 어디 |
|---|---|---|
| 체력 | 1000 (정수) | `BossHealth.maxHp` |
| 이동 · 가속 · 회전 | 3.5 · 8 · 120 | `NavMeshAgent` |
| 근접 거리 | 5m | `BossAttack.attackRange` |
| 추적 시작 거리 | 15m | `BossIdleState` 코드 숫자 |
| 근접 피해 | 20 | 손 뼈의 `L_Box` · `R_Box` — `BossAtkCol.damage` |
| 판단 주기 | 0.2초 | `BossBrain.tickInterval` |
| 바위 던지기 | 표식 1.2초 · 바위 30 · 반경 2m · 높이 5m · 비행 1.2초 | `BossBombSkill` (`warningTime`) · `Prefabs/Projectile` (`BossProjectile`) |
| 둔화 장판 | 반경 5m · ×0.5 · 3초 | `BossSlowSkill` |
| 기절 장판 | 3 ~ 4개 · 8m 안 · 기절 2초 · 3초 유지 | `BossStunZoneSkill` · `Prefabs/StunZone` |
| 스킬 쉼 · 첫 스킬 | 3초 · 2초 뒤 | 각 스킬 `cooldown` · `BossSkillController` 코드 숫자 |
| 등장 시간 | 2초 | `BossTestSpawner` 코드 숫자 |
| 인트로 · 문구 | 9.3초 · "Boss Spawn" · "Start" | `Timeline/TimeLineIntro` · `IntroScene` |
| 배경음 · 등장 소리 | action-1 · forceField_000 | `AUDIO/MusicSet` · `AUDIO/GameSoundSet.bossSpawn` |

- 코드: `Scripts/Boss` (상태 · 움직임 · 근접 · 체력 · 체력 UI) · `Scripts/Boss/BossSkill` (스킬 3종 · 바위 · 기절) · 인트로 `Core/SequenceController` · 엔딩 `Core/EndingSequenceController`
- `BossBombSkill.trackingTime` (0.8) 은 코드에서 쓰지 않는다 — 표식은 `warningTime` 동안 따라온다
- 체력 1000 은 11-12 에 올렸다 (예전 300 — 소총 + 보조 3칸으로 12초에 거의 죽었다)

## 6. 문제점 · 개선 제안

먼저 할 것은 **① 등장 연출을 보스 스테이지 안으로 · ② 체력바 3등분에 맞춘 페이즈 · ③ 근접 공격 예고**다. 세 가지가 들어가면 보스전이 "큰 몬스터 하나"에서 "마지막 클라이맥스"가 된다.

**지금 문제**

| # | 문제 | 내용 |
|---|---|---|
| 1 | 등장이 떨어져 있다 | 인트로 씬에서만 걸어 나와 포효하고, 실제 전투에서는 2초 뒤 그 자리에 그냥 켜진다. 버튼을 눌러야 넘어간다 |
| 2 | 임시 글자 · 소리 | "Boss Spawn" · "Start" · "You Win" 영어 · 인트로 배경음 없음 · 공격 · 스킬 · 피격 · 사망 소리 없음 |
| 3 | 패턴이 단조롭다 | 근접 2종 번갈아 + 스킬 3종 고정 순서 · 페이즈 · 분노 없음 (체력바만 3등분) |
| 4 | 근접 예고가 없다 | 바닥 표시 없이 0.8 ~ 1.5초 뒤 손 판정 — 동작을 보고 피해야 한다 |
| 5 | 맞아도 반응이 없다 | 큰 한 방(공성포 · 태양창 · 붕괴)에도 그대로 · 보스용 피해 숫자 없음 |
| 6 | 정수 피해 | 피해를 정수로 잘라 받아 1 미만은 0 (보조 샷건 탄 등) |
| 7 | 군중 제어가 안 먹힌다 | 경직 · 둔화 · 끌기는 일반 몬스터만 — 의도라면 괜찮지만 알리는 표시가 없다 |
| 8 | 클리어 보상 없음 | 쓰러뜨리면 바로 엔딩 — 판 결과 화면 없음 |
| 9 | 정리 | `BossTestSpawner` (시험용 이름인데 실제 등장) · `BossBrain` "테스트용 반드시 지울것" 주석 · 쓰지 않는 `trackingTime` |

**개선 제안**

| 우선 | 제안 | 내용 |
|---|---|---|
| ★★★ | 등장 연출을 전투 자리에서 | 플레이어 잠깐 멈춤 → 카메라가 보스 자리로 → 바닥 균열 · 등장 이펙트 · 착지 충격파 → 포효(Victory 동작) + 화면 흔들림 · 이름 배너 (예: "균열의 수호 골렘") → 체력바가 차오르며 시작. 인트로 씬은 짧게 자동으로 넘기거나 빼기 |
| ★★★ | 페이즈 3단계 | 1단계 지금 패턴 → 2단계(66%) 바위 2 ~ 3개 연속 · 기절 장판 +2 · 이동 +15% → 3단계(33%) 분노 — 몸 발광(팩의 발광 텍스처) · 새 패턴 · 스킬 쉼 3 → 1.5초. 전환 때 포효 + 무적 1초 + 충격파로 밀쳐 내기 |
| ★★★ | 근접 예고 | 판정 0.5초 전 바닥 부채꼴 · 원 표시 (몬스터 B 돌진 예고처럼) · 예고 소리 |
| ★★ | 새 패턴 후보 | 돌진 (일직선 예고) · 내려찍기 충격파 (바깥으로 퍼지는 고리 — 구르기 · 패링으로 넘기기) · 바위 비 (표식 여럿) · 부하 몬스터 부르기 (보스 스테이지 체력 배율 ×2.5 를 쓸 곳) · 검사가 패링하면 보스가 휘청이는 공격 |
| ★★ | 맞힘 반응 | 큰 한 방에 짧은 GetHit · 누적 피해로 차는 '휘청' 게이지 (차면 1 ~ 2초 무방비 — 군중 제어 대신) · 보스용 피해 숫자 · 번쩍임 |
| ★★ | 정수 피해 고침 | 소수 피해를 쌓아 두었다가 1 이 넘으면 깎기 (또는 체력을 float 로) |
| ★★ | 소리 | 등장 포효 · 발걸음 '쿵' · 휘두름 · 바위 날아감 · 폭발 · 장판 · 페이즈 전환 · 쓰러짐 — 프로젝트 안 Kenney (lowFrequency_explosion · impactPunch_heavy 등) · 인트로 배경음 |
| ★ | 클리어 연출 · 보상 | 쓰러질 때 하얀 섬광 + 짧은 슬로 모션 → 판 결과 화면 (무기별 피해 · 시간 · 빌드) → 엔딩 |
| ★ | 정리 | 문구 한글화 · `BossTestSpawner` 이름 · 테스트 주석 · 쓰지 않는 값 |

- 보스 체력 1000 은 카드 · 스킬 없이 77초 — 페이즈 전환 무적 · 휘청임을 넣으면 조금 더 길어지므로 목표(약 1 ~ 1.5분)에 맞춰 다시 잰다
- 보스 코드 · 씬은 보스 담당(parkjunyoung) 영역이다 — 어느 것을 누가 맡을지 정한 뒤 시작한다
- 정할 것: 인트로 씬을 남길지 · 페이즈 수(2 또는 3) · 보스에게 군중 제어를 먹게 할지(휘청 게이지로 대신할지) · 보스 이름 · 세계관 용어
