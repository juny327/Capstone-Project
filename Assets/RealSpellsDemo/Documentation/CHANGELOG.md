# Changelog - Real Spells Demo

## 1.0.0

First release.

- 10 spells as ready prefabs with their definitions: cast, projectile / beam / strike / nova / ward /
  status, impact, lights, sound, camera shake, hit reaction.
- High / Standard / Mobile sheet tiers, switched from the Tools menu.
- One-line casting API with events and pooling; `SpellCaster`, `SpellReactive`, `SpellCameraShake` components.
- Build Spell From Folder with an example recipe and the recipe reference; a headless package check for agents.
- Demo: a spell browser scene.
