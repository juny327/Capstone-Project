# Real Spells Demo - guide for AI coding agents

Real Spells Demo is a spell VFX pack for Unity 6000.3 with the Universal Render Pipeline (URP 17.3). Package root:
`Assets/RealSpellsDemo`, namespace `RealSpellsDemo`, assemblies `RealSpellsDemo.Runtime`, `RealSpellsDemo.Editor`, `RealSpellsDemo.Demo`. It has no
dependency on any other package and can live in one project with the other Real Spells styles (each style has its
own namespace, assemblies, shader names and GUIDs). The human manual is `Documentation/Manual.md`; the recipe format
is `Documentation/SpellRecipe.md`.

## What is where

- `Spells/<id>/<id>.asset` - `SpellDefinition`: phases (cast, travel, impact, loop, telegraph), flipbook layers,
  lights, sounds, camera shake, feel (timings, hit-stop, reactions). `Spells/<id>/<id>.prefab` - the built
  `SpellPlayer` with its particle systems, lights and audio sources. The definition's `prefab` field points to it.
- `Runtime/SpellPlayer.cs` - plays one spell. Static one-line API:
  `SpellPlayer.Cast(SpellDefinition definition, Transform origin, Transform target, Transform caster = null, bool pooled = true)`
  and the overload with a `Vector3` point. Instance events `Released`, `Contacted(player, point)`, `Finished`;
  `StopLoop()` ends beams, wards and statuses; `StopImmediate()` cuts an effect; `HitWard(point)` plays a ward's hit
  reaction; `ShellPoint(from)` gives the point on a ward's shell facing an attacker. Fields set before a cast:
  `hitMask` (what a projectile can hit), `ignoreRoot` (colliders under it are flown through; `Cast` sets it to the
  `caster` argument), `playAudio`, `casterBody` / `targetBody` (body centres for wards and statuses),
  `reactionTarget`. `SweepHit(from, dir, dist, out hit)` is the projectile's own collider test.
- Static on `SpellPlayer`: `LightScale` (multiplies every spell light, default 1); events
  `PhaseStarted(player, phase, time)`, `SoundEvent(SpellSoundEvent)`, `ScreenFlash(player, color, strength, frames)`,
  `StatusChanged(player, on)`.
- `Runtime/SpellPool.cs` - pooled instances (`Get`, `Prewarm`, `Release`). `Runtime/SpellCaster.cs` - component
  (`spell`, `hand`, `hitMask`, `ignoreRoot`, `CastAt(Transform)` / `CastAt(Vector3)`).
- `Runtime/SpellReactive.cs` - put on targets: hit flash, knockback, status tint and shiver.
- `Runtime/SpellCameraShake.cs` - put on the camera (`strength`).
- `Settings/SpellShaders.asset` - the package's shaders referenced by asset (no `Shader.Find`, no `Resources`).
- `Settings/SpellQualitySettings.asset` - package-wide sheet tier; `Editor/SpellTierTool.cs` applies tiers
  (`SpellTierTool.SetGlobal(SpellTier.Mobile)`).
- `Editor/SpellPrefabBuilder.cs` - `Tools > Real Spells Demo > Build Spell From Folder...`, in code
  `SpellPrefabBuilder.Build(string spellFolder, List<string> warnings)` returns the prefab path. It builds a spell
  from a recipe folder (`spell.json`, schema `realspells.spell/1`; sheets `realspells.sheet/1`). A complete example
  recipe ships in `Documentation/ExampleRecipe/spells/example_shadow_bolt/`.
- `Editor/SpellVerify.cs` - headless check of the package (see Verify).
- `Demo/` - demo scene `Demo/ArenaDemo.unity` and its scripts (`SpellDemoBrowser`); not needed at run time by a game.

## Ids

Spells: `fireball`, `meteor`, `frost_nova`, `frost_ray`, `frozen`, `thunder_strike`, `divine_shield`, `shadow_bolt`, `poison_cloud`, `stone_spikes`.

## Recipes

1. Cast at an enemy: `SpellPlayer.Cast(definition, handTransform, enemyTransform, casterRoot);` Subscribe to
   `Contacted` to apply damage on the frame the spell lands; unsubscribe in the handler (instances are pooled).
2. Channelled spell (beam, ward, status): keep the returned instance, call `StopLoop()` when the button is released.
3. Smaller builds: `Tools > Real Spells Demo > Quality Tier > Mobile` (or Standard), or set the tier on single definitions.
   A build contains only the tier in use and only the spells that scenes and prefabs reference.
4. Make a target react: add `SpellReactive` to its root and a collider to its body.
5. Stop a beam at a wall: raycast yourself, then `Cast(definition, hand, hitPoint)`. Only projectiles test colliders.
6. Avoid the first-cast hitch: `SpellPool.Prewarm(definition, 2)` while loading.

## Rules

- Do not edit the shaders' property names; materials are generated by the builder from the definitions.
- Spells read no files at run time; everything is an asset. Keep the definitions, prefabs, materials and sheets
  together when moving the package root.
- Do not add `using` of `RealSpellsDemo.Demo` to game code that must survive deleting those folders.

## Limits

- URP only (Unity 6000.3, URP 17.3); Built-in and HDRP render the materials pink.
- Flipbook sprites with real point lights: no volumetrics, no shadows from the effects.
- Only projectiles sweep colliders; beams, novas, strikes, wards and statuses address the target passed to `Cast`.
- `ScreenFlash` is an event only: nothing draws the flash outside the demo.
- Tested on Windows (editor and player, Direct3D 11) with the Forward renderer.

## Verify

1. Headless: run Unity with `-batchmode -projectPath <project> -executeMethod RealSpellsDemo.Editor.SpellVerify.Run -quit`
   (or the menu `Tools > Real Spells Demo > Verify Package`). It checks every spell and circle of the package (definition,
   prefab with its `SpellPlayer`, a material and a sheet texture on every layer, every sound clip, the shader set)
   and logs one line: `Real Spells verify: OK spells=<n> circles=<n> problems=0`. With problems the line says `FAIL`,
   each problem is logged before it, and in batch mode the editor exits with code 1.
2. In a script: `var p = SpellPlayer.Cast(def, hand, target); p.Finished += _ => Debug.Log("done");` - the log line
   appears once the effect has faded (2-4 s for a bolt).
3. By eye: open `Assets/RealSpellsDemo/Demo/ArenaDemo.unity`, enter Play mode, press the on-screen `Cast` button: the
   selected spell casts and the dummy reacts; the Console stays free of errors and warnings.
4. After switching tiers, a material under `Spells/<id>/Materials` shows the chosen tier's sheet as its texture.
