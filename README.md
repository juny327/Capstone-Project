# Monster B 돌진 변경

- 공격 준비 거리 6, 평상시 이동 속도 2. 기존 공격력 5 유지.
- 0.9초 동안 방향이 고정된 직사각형 경로, 내부 화살표, 차오르는 색 표시.
- 출발 0.15초 전에 0.12초 길이의 짧은 합성 효과음.
- 최대 6 거리, 속도 8로 직선 돌진. 벽과 NavMesh 끝에서는 경로 단축.
- 종료 후 1초간 정지, 이후 3초 쿨타임.
- 표시 폭 1.4 (몸체 지름보다 작아지지 않음). 앞뒤 몸체 반지름 포함.
- DashFootprint를 표시와 연속 이동 피해 검사에서 공유. 플레이어의 감지용 트리거는 피해 판정에서 제외.
- 같은 돌진에서 플레이어는 한 번만 피해. 예고 중에는 피해 없음.
- 피격·사망·풀 반환·플레이어 사망으로 취소하면 표시와 소리 정리.
- 공통 Enemy의 생성 시 NavMesh 초기화를 최종 위치 배치 뒤로 이동. 치명타 사망 후 Hit 상태로 바뀌는 문제도 방지.

## 적용
Assets 폴더를 프로젝트에 병합. 새 .meta 파일도 함께 적용해야 프리팹의 연결이 유지됩니다.
생성 주기 및 1마리 75% / 2마리 25% 확률 설정은 변경하지 않습니다.

## 검증
Unity 6000.3.7f1의 C# 컴파일러 및 프로젝트 참조 DLL로 전체 C# 소스 컴파일 통과.
1000가지 크기·거리·이동 구간에 대해 피해 영역이 예고 범위에 포함되는지 등 28,228개 단언 통과.
프리팹 -> 스크립트 / 머티리얼 -> 셰이더 GUID 연결 확인.
Unity 라이선스 문제로 플레이 모드 실행, 셰이더 임포트·시각·소리·실제 충돌 확인은 미완료.

## Unity에서 확인할 시나리오
1. B가 플레이어를 향해 예고한 후 플레이어가 옆으로 이동: 경로 방향 유지, 범위 밖이면 피해 없음.
2. 플레이어 몸통 콜라이더가 표시 영역과 겹치면 가장자리에서도 피격 가능. 감지용 큰 구체는 무시.
3. 경로 끝에는 몬스터 반지름까지 표시됨. 실제 피해 박스가 표시를 넘어가지 않는지 확인.
4. 벽 앞에서 예고 길이 단축, 돌진 중 벽이 나타나면 조기 정지.
5. 돌진 중 여러 프레임 접촉해도 피해 1회. 점프로 몸체 높이 이상 벗어나면 피해 없음.
6. 예고/돌진 중 치명타나 사망: 표시가 즉시 사라짐. 풀에서 재생성되어도 정상 재공격.
